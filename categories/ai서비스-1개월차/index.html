CSS의 미디어 쿼리(@media)를 사용하면 화면 조건에 따라 같은 요소에 다른 스타일을 적용할 수 있다. 미디어 쿼리로 화면 크기에 대응하기 미디어 쿼리는 특정 조건을 만족할 때만 CSS 규칙을 적용하는 구문이다. 아래 예시는 기본적으로 빨간색 500px 정사각형을 표시하고, 화면 너비가 320px 이상 800px 이하일 때는 노란색 300px 정사각형으로 바꾼다. .media { width: 500px; height: 500px; background-color: red; } @media (min-width: 320px) and (max-width: 800px) { .media { width: 300px; height: 300px; background-color: yellow; } } min-width와 max-width를 함께 사용하면 적용할 화면 폭 구간을 정할 수 있다. 브라우저 개발자 도구(F12)의 반응형 기기 모드에서 화면 폭을 변경하며 규칙이 의도대로 전환되는지 확인할 수 있다. ...
