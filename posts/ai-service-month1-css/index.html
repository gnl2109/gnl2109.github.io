    CSS#

    CSS란?#

    CSS(Cascading Style Sheet)는 HTML로 작성한 정보와 디자인을 분리하고, 문서의 레이아웃과 스타일을 정의하는 언어다.

    기본 구성은 다음과 같다.

    선택자 { 속성: 속성값; }
    • 선택자: 디자인을 적용할 HTML 영역
    • 속성: 적용할 디자인의 종류. 예: color, font-size
    • 속성값: 속성이 수행할 구체적인 명령. 각 선언 끝에는 세미콜론(;)을 입력한다.
    h1 {
  font-size: 20px;
  font-family: sans-serif;
  color: blue;
  background-color: yellow;
  text-align: center;
}

    CSS를 연결하는 세 가지 방법#

    Inline Style Sheet#

    HTML 태그의 style 속성에 직접 작성한다.

    <h1 style="color: red;">coding</h1>

    Internal Style Sheet#

    HTML 문서의 head 안에 style 태그로 작성한다.

    <head>
  <style>
    h1 { background-color: yellow; }
  </style>
</head>

    External Style Sheet#

    별도의 CSS 파일을 연결한다.

    <head>
  <link rel="stylesheet" href="style.css">
</head>

    /* style.css */
h1 {
  font-style: italic;
}

    CSS 선택자#

    선택자는 HTML의 어떤 요소에 CSS를 적용할지 정한다.

    Type Selector#

    특정 태그에 스타일을 적용한다.

    h2 { color: red; }

    Class Selector#

    클래스 이름 앞에 점(.)을 붙여 스타일을 적용한다.

    <h2 class="coding">Class Hello World</h2>

    .coding { color: blue; }

    ID Selector#

    ID 이름 앞에 샵(#)을 붙여 스타일을 적용한다.

    <h2 id="coding">ID Hello World</h2>

    #coding { color: green; }

    부모·자식 관계와 상속#

    부모 태그의 CSS 속성은 자식 태그에 상속될 수 있다. 단, 부모와 자식이 같은 속성에 서로 다른 값을 가지면 자식은 자신의 값을 사용한다.

    <header>
  <h1>Header h1</h1>
  <p>Header p</p>
</header>
<footer>
  <h1>Footer h1</h1>
  <p>Footer p</p>
</footer>

    header { color: red; }
header h1 { color: blue; }
footer p { color: green; }

    위 예시에서 header는 h1, p의 부모이며, h1과 p는 형제 관계다.

    캐스케이딩과 우선순위#

    CSS 우선순위는 크게 순서, 구체성, 선택자 종류로 결정된다.

    1. 같은 조건이면 나중에 작성한 규칙이 우선한다.
    2. 더 구체적으로 작성한 선택자가 우선한다.
    3. 일반적으로 style > id > class > type 순으로 우선순위가 높다.
    p { color: red; }
p { color: blue; } /* 나중에 작성한 값이 적용 */

header p { color: red; } /* p보다 구체적인 선택자 */

#color { color: blue; }
.color { color: red; }
h3 { color: green; }

    주요 CSS 속성#

    크기#

    width, height로 요소의 너비와 높이를 설정한다. px는 고정값, %는 가변값이다.

    .paragraph { width: 500px; height: 500px; }

    글꼴#

    .paragraph {
  font-size: 50px;
  font-family: Arial, sans-serif;
  font-style: italic;
  font-weight: bold;
}

    테두리#

    .paragraph {
  width: 500px;
  height: 500px;
  border-style: solid;
  border-width: 10px;
  border-color: red;
  /* border: solid 10px red; */
}

    배경#

    .paragraph {
  background-color: yellow;
  background-image: url(이미지 경로);
  background-repeat: no-repeat;
  background-position: left;
  /* background: yellow url(이미지 경로) no-repeat left; */
}
