    HTML#

    웹을 구성하는 요소#

    웹사이트는 HTML, CSS, JavaScript로 구성된다.

    • HTML: 정보와 구조를 표현하는 설계도
    • CSS: 디자인과 스타일링
    • JavaScript: 기능과 효과

    웹사이트를 제작할 때는 다음도 함께 고려해야 한다.

    • 웹 표준: 따라야 하는 공식 표준과 기술 규격
    • 웹 접근성: 장애 여부와 관계없이 모두가 이용할 수 있도록 하는 방식
    • 크로스 브라우징: 모든 브라우저와 기기에서 사이트가 제대로 작동하도록 하는 기법

    HTML(Hyper Text Markup Language)은 웹사이트에서 보이는 정보나 특정 구역을 설정할 때 사용하는 언어다.

    HTML 기본 태그#

    기본적인 태그 구조는 다음과 같다.

    <열린태그 속성="속성값">콘텐츠</닫힌태그>

    HTML 문서의 기본 구조는 아래와 같다.

    <!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>웹프로그래밍</title>
  </head>
  <body>
  </body>
</html>
    • <!DOCTYPE html>: HTML5 문서임을 선언
    • <html>: HTML 문서의 시작과 끝
    • <head>: 웹사이트의 요약 정보
    • <meta charset="UTF-8">: 문자 코드 지정
    • <title>: 브라우저 탭 제목
    • <body>: 화면에 보이는 웹사이트 내용

    자주 사용하는 태그#

    • <img>: 정보성을 갖는 이미지를 삽입하는 닫는 태그가 없는 요소

      <img src="logo.png" alt="회사로고">

      src는 이미지 파일 경로이며, alt는 이미지 출력에 실패했을 때 대체할 텍스트 정보다.

    • <h1>~<h6>: 제목과 부제목. h1이 가장 큰 제목이다.

    • <p>: 본문 단락.

    • <ul>: 순서 없는 목록. 메뉴 등에 활용한다.

    • <ol>: 순서 있는 목록.

    구조를 잡는 시맨틱 태그#

    header, nav#

    <header>
  <img src="elice_logo.png" alt="엘리스 로고">
  <nav>
    <ul>
      <li>홈</li>
      <li>전체 목록</li>
    </ul>
  </nav>
</header>
    • header: 웹사이트의 머리글을 담는 상단 영역
    • nav: 메뉴 버튼을 담는 내비게이션 영역

    main, article#

    <main role="main">
  <article>
    <h1>제목</h1>
  </article>
</main>
    • main: 문서의 주요 본문 영역
    • article: 주요 이미지와 텍스트 같은 독립적인 정보 영역
    • article 안에는 제목이 있어야 한다.

    footer#

    <footer>
  <div>
    <p>주소: ㅇㅇ시 ㅇㅇ구 ㅇㅇ로</p>
    <p>이메일: contact@elice.io</p>
  </div>
  <div>
    <p>사업자등록번호: 000-00-00000 | 대표: 엘토끼</p>
    <p>통신판매업신고번호: 제0000-토끼굴-0000호</p>
  </div>
</footer>

    footer는 웹페이지 가장 하단의 회사 정보나 필수 고지 정보를 표기하는 영역이다.

    Block 요소와 Inline 요소#

    • Block 요소는 세로 방향으로 배치되고 줄바꿈이 발생한다. 공간을 설정하거나 상하 배치 작업을 할 수 있다. 대표 태그는 h, p다.
    • Inline 요소는 가로 방향으로 배치되고 줄바꿈이 발생하지 않는다. 공간을 만들거나 상하 배치 작업을 할 수 없다. 대표 태그는 a다.
    <p>Hello</p>
<p>Hello</p>
<p>Hello</p>
<a>Bye</a>
<a>Bye</a>
<a>Bye</a>

    위 코드에서 p 태그는 줄마다 표시되고, a 태그는 같은 줄에 이어서 표시된다.
