    반응형 웹사이트 제작#

    반응형 웹사이트는 PC, 태블릿, 모바일처럼 화면 크기가 다른 환경에서도 콘텐츠가 읽기 좋게 보이도록 구성한 웹사이트다. CSS의 미디어 쿼리(@media)를 사용하면 화면 조건에 따라 같은 요소에 다른 스타일을 적용할 수 있다.

    미디어 쿼리로 화면 크기에 대응하기#

    미디어 쿼리는 특정 조건을 만족할 때만 CSS 규칙을 적용하는 구문이다. 아래 예시는 기본적으로 빨간색 500px 정사각형을 표시하고, 화면 너비가 320px 이상 800px 이하일 때는 노란색 300px 정사각형으로 바꾼다.

    .media {
  width: 500px;
  height: 500px;
  background-color: red;
}

@media (min-width: 320px) and (max-width: 800px) {
  .media {
    width: 300px;
    height: 300px;
    background-color: yellow;
  }
}

    min-width와 max-width를 함께 사용하면 적용할 화면 폭 구간을 정할 수 있다. 브라우저 개발자 도구(F12)의 반응형 기기 모드에서 화면 폭을 변경하며 규칙이 의도대로 전환되는지 확인할 수 있다.

    viewport 설정#

    모바일 화면에서 미디어 쿼리가 의도대로 동작하려면 문서의 head에 viewport 메타 태그를 넣는다.

    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    • width=device-width: viewport의 가로폭을 기기의 가로폭에 맞춘다.
    • initial-scale=1.0: 페이지를 처음 표시할 때 확대·축소 비율을 1로 설정한다.

    viewport는 디지털 기기의 화면에 표시되는 웹페이지 영역을 뜻한다. 이 설정이 없으면 모바일 브라우저가 데스크톱 폭을 기준으로 페이지를 축소해 보여 주어 반응형 스타일이 기대와 다르게 보일 수 있다.

    미디어 쿼리 안의 스타일 작성 원칙#

    미디어 쿼리 안에서는 바꾸려는 속성만 다시 선언하면 된다. 같은 선택자와 속성에 대해 조건부 규칙이 적용되면 해당 조건의 값이 기본값을 덮어쓴다.

    .media {
  width: 500px;
  height: 500px;
  background-color: red;
}

@media (min-width: 320px) and (max-width: 800px) {
  .media {
    width: 300px;
    height: 300px;
    background-color: transparent;
  }
}

    background-color: none은 유효한 색상값이 아니다. 배경을 투명하게 만들려면 transparent를 사용하고, 기본 규칙의 색상을 그대로 유지하려면 해당 속성을 미디어 쿼리 안에 작성하지 않는다.

    정리#

    1. @media는 화면 폭 같은 조건에 따라 CSS를 다르게 적용한다.
    2. 모바일 대응을 위해 viewport 메타 태그를 head에 추가한다.
    3. 미디어 쿼리에서는 변경할 속성만 재선언하고, 유효한 CSS 값인지 확인한다.
