    웹사이트에 영향을 미치는 요소#

    박스 모델#

    CSS 박스 모델은 바깥쪽부터 margin > border > padding > content 순으로 구성된다.

    • margin: border 바깥쪽 여백
    • padding: border 안쪽 여백
    • border: 요소의 테두리
    • content: 실제 콘텐츠 영역
    div {
  margin-left: 100px;
  padding-left: 100px;
}

div { margin: 100px 0 0 100px; }
/* top right bottom left 순으로 한 줄에 작성 가능 */

    Block 요소와 Inline 요소#

    Block 요소#

    • y축 방향으로 정렬
    • 대표적으로 p 태그
    • 줄바꿈 현상 발생
    • width, height를 사용할 수 있어 공간 생성 가능
    • margin, padding으로 상하 배치 작업 가능

    Inline 요소#

    • x축 방향으로 정렬
    • 대표적으로 a, span 태그
    • 줄바꿈 현상 없음
    • width, height 적용 불가
    • margin-top, margin-bottom, padding-top, padding-bottom 적용 불가
    <style>
  p {
    width: 200px;
    height: 200px;
    margin-top: 100px;
  }
  a {
    width: 200px;      /* inline 요소에서는 적용되지 않음 */
    height: 200px;     /* inline 요소에서는 적용되지 않음 */
    margin-top: 100px; /* inline 요소에서는 적용되지 않음 */
  }
</style>

    마진 병합 현상#

    형제 요소의 마진 병합#

    세로 마진이 만날 때 두 값이 더해지지 않고 더 큰 값으로 적용되는 현상이다.

    <div class="box1">Hello World</div>
<div class="box2">Hello World</div>

    .box1 { margin-bottom: 150px; }
.box2 { margin-top: 100px; }

    위 예시에서는 150px이 적용되고 100px은 별도로 더해지지 않는다.

    부모·자식 요소의 마진 병합#

    자식 요소의 세로 마진이 부모 요소에도 영향을 미칠 수 있다.

    <main role="main">
  <article></article>
</main>

    article {
  width: 200px;
  height: 200px;
  margin-top: 100px;
}

    레이아웃에 영향을 미치는 속성#

    display#

    Block과 Inline 요소의 성격을 바꿀 때 사용한다.

    p { display: inline; }
a { display: block; }
a { display: inline-block; }

    inline-block은 Block과 Inline의 성격을 함께 가진다.

    float#

    선택한 요소를 왼쪽 또는 오른쪽 끝에 정렬하고, 새로운 레이어처럼 배치할 때 사용한다.

    <div class="left">Hello World</div>
<div class="next">Hello World</div>
<div class="right">Hello World</div>

    .left { float: left; }
.next { float: left; }
.right { float: right; }

    clear#

    float로 변경된 레이어 배치를 해제할 때 사용한다.

    footer { clear: both; }

    브라우저 기본 여백 제거#

    html, body 태그는 기본 margin, padding 값을 가지므로 필요에 따라 초기화한다.

    html, body {
  margin: 0;
  padding: 0;
}

    또는 전체 선택자를 사용할 수 있다.

    * {
  margin: 0;
  padding: 0;
}
