[이어드림스쿨6기_1개월] 리눅스 기초 실습 01

2026년 5월 31일

강의자료/0531_linux_tutorial_01.md를 바탕으로, 터미널에서 현재 위치를 확인하고 디렉터리와 파일을 만들고 옮기고 삭제하는 기본 흐름을 정리했다.

이번 실습의 핵심은 명령어를 하나씩 외우는 것보다, 터미널에서 “내가 어디에 있고, 무엇을 만들고, 어떻게 확인하고, 어떻게 정리할지"를 순서대로 익히는 것이다.

1. 현재 위치 확인하기#

터미널 작업은 현재 내가 어느 디렉터리에 있는지 확인하는 것에서 시작한다. 위치를 모르고 명령어를 실행하면 엉뚱한 곳에 파일을 만들거나 삭제할 수 있다.

현재 디렉터리의 절대 경로를 확인할 때는 pwd를 사용한다.

$ pwd
C:/Users/gnl21/Desktop/TEST

원하는 디렉터리로 이동할 때는 cd를 사용한다. 예를 들어 바탕화면으로 이동하려면 다음처럼 입력한다.

$ cd ~/Desktop

현재 위치에 있는 파일과 폴더 목록은 ls로 확인한다.

$ ls
0528/

숨김 파일까지 포함해서 자세히 보고 싶다면 ls -al을 사용한다.

$ ls -al
total 4
drwxr-xr-x 1 PC 197121 0 May 28 10:10 ./
drwxr-xr-x 1 PC 197121 0 May 28 10:28 ../
drwxr-xr-x 1 PC 197121 0 May 28 10:12 0528/

여기서 .은 현재 디렉터리, ..은 상위 디렉터리를 의미한다.

2. 폴더 만들고 이동하기#

새 폴더를 만들 때는 mkdir을 사용한다.

mkdir linux_practice

여러 단계의 중첩 폴더를 한 번에 만들고 싶다면 -p 옵션을 붙인다.

mkdir -p linux_practice/src/utils

만든 폴더로 이동할 때는 cd를 사용한다.

cd linux_practice

상위 폴더로 돌아갈 때는 cd ..을 입력한다.

cd ..

작업 중에는 pwd와 ls를 자주 함께 쓰는 습관을 들이면 좋다. 현재 위치를 확인하고, 그 위치에 어떤 파일과 폴더가 있는지 보는 것이 터미널 사용의 기본 리듬이다.

3. 파일 만들고 내용 확인하기#

빈 파일을 만들 때는 touch를 사용한다.

cd ~/Desktop/test/linux_practice
touch hello.txt

파일에 내용을 넣을 때는 echo와 리다이렉션을 사용할 수 있다.

echo "hello, Linux!" > hello.txt
echo "두 번째 줄 추가" >> hello.txt

>는 기존 내용을 덮어쓰고, >>는 기존 내용 뒤에 이어 쓴다. 실습이 아니라 실제 파일을 다룰 때는 >를 조심해야 한다. 기존 내용이 사라질 수 있기 때문이다.

파일 내용을 확인할 때는 cat을 사용한다.

cat hello.txt

cat은 파일 전체 내용을 터미널에 출력한다. 짧은 설정 파일이나 간단한 메모를 확인할 때 유용하다.

4. vi 편집기 기본 사용법#

터미널 환경에서는 텍스트 편집기를 사용할 일이 많다. vi는 서버 환경에서도 자주 만나는 편집기라, 최소한의 저장과 종료 방법은 익혀두는 것이 좋다.

vi memo.txt

vi는 일반 모드와 삽입 모드가 나뉘어 있다. 처음 열면 일반 모드이고, 글자를 입력하려면 삽입 모드로 들어가야 한다.

키 동작
i 삽입 모드 진입
ESC 일반 모드로 복귀
:w 저장
:q 종료
:wq 저장 후 종료
:q! 저장하지 않고 강제 종료

처음에는 i로 입력을 시작하고, ESC로 일반 모드로 돌아간 뒤, :wq로 저장하고 종료하는 흐름만 익혀도 충분하다.

5. 파일과 폴더 복사하기#

파일을 복사할 때는 cp를 사용한다.

cp hello.txt hello_backup.txt

위 명령은 hello.txt를 복사해서 hello_backup.txt를 만든다.

폴더 전체를 복사할 때는 -r 옵션을 붙인다.

cp -r linux_practice/ linux_practice_backup/

-r은 하위 파일과 폴더를 재귀적으로 함께 복사하겠다는 뜻이다.

6. 파일과 폴더 이동하거나 이름 바꾸기#

파일이나 폴더를 이동할 때는 mv를 사용한다. 같은 위치에서 다른 이름을 지정하면 이름 변경처럼 동작한다.

mv hello_backup.txt hello_copy.txt

특정 폴더로 파일을 옮길 수도 있다.

mkdir archive
mv hello_copy.txt archive/

원본 강의자료에는 archieve라는 폴더명이 섞여 있었는데, 일반적인 철자는 archive다. 실습할 때는 폴더 이름을 동일하게 맞춰야 mv 명령이 실패하지 않는다.

7. 파일과 폴더 삭제하기#

파일을 삭제할 때는 rm을 사용한다.

rm memo.txt

폴더 전체를 삭제할 때는 -r 옵션을 붙인다.

rm -r archive

강제로 삭제할 때는 -f 옵션을 함께 사용할 수 있다.

rm -rf 폴더/파일/...

다만 rm -rf는 매우 위험하다. 휴지통을 거치지 않고 삭제되기 때문에, 현재 위치와 삭제 대상을 반드시 확인한 뒤 사용해야 한다. 실무에서는 삭제 전에 pwd, ls, 삭제할 경로를 한 번 더 확인하는 습관이 중요하다.

마무리#

이번 실습은 리눅스 명령어의 가장 기본적인 흐름을 다룬다. 현재 위치를 확인하고, 이동하고, 파일과 폴더를 만들고, 내용을 확인하고, 복사와 이동과 삭제를 수행하는 과정이다.

1. 핵심 주장#

터미널 사용의 기본은 “현재 위치 확인 → 목록 확인 → 작업 실행 → 결과 확인"이다. 이 순서를 습관으로 만들면 파일을 잘못 만들거나 삭제하는 실수를 줄일 수 있다.

2. 중요한 명령어#

  • pwd: 현재 디렉터리 위치를 확인한다.
  • cd: 원하는 디렉터리로 이동한다.
  • ls: 파일과 폴더 목록을 확인한다.
  • ls -al: 숨김 파일과 상세 정보를 함께 확인한다.
  • mkdir: 새 디렉터리를 만든다.
  • mkdir -p: 중첩 디렉터리를 한 번에 만든다.
  • touch: 빈 파일을 만든다.
  • echo: 문자열을 출력하거나 파일에 쓴다.
  • cat: 파일 내용을 출력한다.
  • vi: 터미널 기반 편집기를 실행한다.
  • cp: 파일이나 폴더를 복사한다.
  • mv: 파일이나 폴더를 이동하거나 이름을 바꾼다.
  • rm: 파일이나 폴더를 삭제한다.

3. 내가 놓치기 쉬운 부분#

>와 >>의 차이를 놓치기 쉽다. >는 덮어쓰기라 기존 내용이 사라지고, >>는 기존 내용 뒤에 추가된다.

mv는 이동과 이름 변경을 모두 담당한다. 그래서 명령어 자체보다 “원본 경로와 대상 경로를 어떻게 썼는지"가 중요하다.

rm -rf는 편하지만 위험하다. 삭제 명령을 실행하기 전에는 반드시 현재 위치와 삭제 대상을 확인해야 한다.

4. 나에게 물어볼 질문 5개#

  1. 지금 터미널에서 내가 어느 위치에 있는지 확인하는 명령어를 바로 말할 수 있을까?
  2. 현재 폴더의 숨김 파일과 자세한 정보를 확인하려면 어떤 옵션을 붙여야 할까?
  3. >와 >>는 각각 파일 내용을 어떻게 바꿀까?
  4. mv hello.txt archive/와 mv hello.txt hi.txt는 각각 어떤 작업일까?
  5. rm -rf를 실행하기 전에 반드시 확인해야 할 것은 무엇일까?
