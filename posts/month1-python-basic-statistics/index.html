    파이썬 확률 통계#

    수치를 통한 연속형 자료 요약#

    1. 중심위치의 측도(measure of center) : 자료의 중심위치를 나타냄
    2. 퍼진 정도의 측도(measure of dispersion) : 자료가 각 중심위치로부터 얼마나 흩어져 있는지 나타냄
    3. 도수분포표 : 자료가 이미 그룹화된 경우의 수치 요약 방법
    4. 상자 그림 : 사분위수, 최솟값, 최댓값 등을 이용한 요약 방법

    중심위치의 측도#

    • 평균 np.mean() : 모든 관측값의 합을 자료의 개수로 나눈 값. 관측값들의 무게중심. 극단값의 영향을 받음.

    • 중앙값 np.median() : 전체 관측값을 정렬했을 때 가운데에 위치하는 값. 극단값의 영향을 받지 않음.

    • 최빈값 stats.mode() : 관측값 중 가장 자주 나오는 값. 이산형/범주형 자료에서 많이 사용.

    • 실제 사용 빈도 : 평균 > 중앙값 > 최빈값

      • 극단값 영향을 배제하고 싶으면 중앙값, 전체 관측값 포함하고 싶으면 평균 사용
      • 단봉형 분포에서는 최빈값 유용

    퍼진 정도의 측도#

    • 분산 variance() : 각 관측값이 자료의 평균으로부터 떨어진 정도. 편차의 제곱합으 관측갯수로 나눈 값. s^2 으로 표기.

    • 표준편차 stdev() : 분산의 제곱근. s 로 표기.

    • 범위(Range) np.max()-np.min() : 관측값에서 가장 큰 값과 가장 작은 값의 차이. 극단값의 영향이 큼.

    • 백분위수 np.percentile() : 자료를 순서대로 정렬했을 때 백분율로 특정 위치의 값을 표현. 데이터를 작은 순서대로 나열했을 때, 전체의 몇 % 지점에 해당하는 값.

    • 사분위수 : 백분위수의 일종으로 전체를 사등분하는 값.

      • 제1사분위수 np.percentile(a, 25) = 제25백분위수(Q1)
      • 제2사분위수 np.percentile(a, 50) = 제50백분위수(Q2) = 중앙값
      • 제3사분위수 np.percentile(a, 75) = 제75백분위수(Q3)
      • 사분위수 범위 IQR = Q3 - Q1 : 관측값의 중간 50%에 대한 범위

    • 퍼진 정도의 측도 비교 (표준편차, 범위, 사분위수)

      • 평균의 특징 = 표준편차의 특징 / 중앙값의 특징 = 사분위수 범위의 특징
      • 표준편차 : 전체 관측값의 퍼진 정도를 골고루 반영. 극단값의 영향을 받음.
      • 사분위수 범위 : 극단값의 영향을 안받음. Q1~Q3 사이의 관측값에 대한 분포를 반영하지 않음.
      • 범위 : 퍼진 정도. 표준편차의 단점, 사분위수 범위의 단점을 모두 가짐.

    • 변동계수 CV=표준편차/평균 x 100 : 퍼진 정도를 상대적으로 나타내는 수치를 사용. 비교대상의 단위가 다른 경우, 변동계수를 통해 퍼진 정도 비교.

    도수분포표#

    • 원자료(개별데이터)가 없을 때 계급의 중간값을 대신 사용하여 근사 계산.
    • 그룹화에 의한 정보가 상실되기 때문에 가능하다면 원자료를 이용.
    • 예시) 학생 30명의 키가 있을때 구간(계급)으로 묶인 도수분포표
      • 160~164: 4명 / 165~169: 10명 / 170~174: 12명 / 175~179: 4명
      • 각 학생의 키가 몇인지는 알 수 없음(원자료가 없음)
      • 계산을 위해 계급의 한가운데(중간값)에 있다고 가정함. 162 / 167 / 172 / 177
      • 평균계산 (162*4 + 167*10 + 172*12 + 177*4) / 30
      • 분산, 표준편차도 각 계급의 중간값을 실제데이터처럼 사용하여 계산.

    상자그림(boxplot)#

    • 상자그림 plt.boxplot() : 다섯가지 요약수치(최솟값, Q1, Q2, Q3, 최댓값)를 그림으로 표현.
    • 제1사분위수에서 제3분위수까지 상자로 그리고, 좌우에 선을 그어 최솟값, 최댓값을 나타냄.

    두 변수 자료의 요약#

    범주형 자료 요약#

    • 분할표 pd.crosstab(index = 기준 범주, columns = 관측 범주)
      • 두 개의 범주형 변수(category variable)가 서로 어떤 관계를 가지는지 확인하는 표. 쉽게 말하면 A와 B가 동시에 나타나는 횟수를 세어놓은 표.
      • 성별/혈액형ABO
        남201525
        여18814

    수치형 자료 요약#

    • 산점도 plt.scatter(x = x축변수, y = y축변수)
      • 연속형 변수 각각의 관측값을 좌표평면에 표시. 두 변수 사이의 관계를 시각적으로 파악.
    • 공분산 df[x].cov(df[y])
      • 두 변수가 함께 어떻게 변하는지를 나타내는 값.
      • 두 변수의 편차를 곱하여 더한 후 자료의 개수(N)으로 나누어줌.
      • 값이 같이 움직이면 양수, 반대로 움직이면 음수, 0에 가까우면 뚜렷한 선형 관계가 없음.
      • 공분산만 쓰면 값이 큰지 작은지 판단하기 어려움.
    • 상관계수 df[x].corr(df[y])
      • 산점도의 점들이 직선에 가까운 정도를 수치로 나타내어 관계를 파악.
      • 상관계수는 보통 r로 표시. 항상 -1과 1사이에 있음.
      • 상관계수는 직선 관계만을 나타냄.
      • 자료분석 시, 큰 상관계수값이 항상 두 변수사이의 인과관계를 가지진 않는다.
      • 예시) 상어에 물린 사고 횟수와 아이스크림 판매량의 상관관계 -> 직접적인 인과관계는 상어와 아이스크림이 아니라, 여름철이기 때문이다.
