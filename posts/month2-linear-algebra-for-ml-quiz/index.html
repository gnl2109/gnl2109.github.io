선형대수 기초 퀴즈 정리#

머신러닝을 위한 선형대수 기초 수업에서 다룬 벡터 내적, 노름, 행렬 곱셈, 연립방정식 풀이를 퀴즈 형태로 정리했다. 계산 자체도 중요하지만, 각 연산이 어떤 의미를 갖는지 함께 확인하는 것이 핵심이다.

퀴즈 1. 벡터의 내적과 노름#

문제는 다음 두 벡터가 주어졌을 때 내적과 각 벡터의 노름을 구하는 것이다.

$$x=(1,-1,0,2,4), \quad y=(2,1,1,3,0)$$

내적#

$$\langle x, y \rangle = (1)(2) + (-1)(1) + (0)(1) + (2)(3) + (4)(0)$$

성분 x y x * y
1번째 1 2 2
2번째 -1 1 -1
3번째 0 1 0
4번째 2 3 6
5번째 4 0 0

따라서 내적은 다음과 같다.

$$\langle x,y \rangle = 2 + (-1) + 0 + 6 + 0 = 7$$

노름#

벡터의 노름은 각 성분을 제곱해 더한 뒤 제곱근을 취한다.

$$|x| = \sqrt{1^2 + (-1)^2 + 0^2 + 2^2 + 4^2} = \sqrt{22}$$

$$|y| = \sqrt{2^2 + 1^2 + 1^2 + 3^2 + 0^2} = \sqrt{15}$$

정답은 다음과 같다.

$$\langle x,y \rangle = 7, \quad |x| = \sqrt{22}, \quad |y| = \sqrt{15}$$

import numpy as np

# 벡터 정의
x = np.array([1, -1, 0, 2, 4])
y = np.array([2, 1, 1, 3, 0])

# (1) <x, y> => 내적 연산
inner = np.dot(x, y)
print(f"<x, y> = {inner}")

# (2) ||x|| norm 노름
norm_x = np.linalg.norm(x)
print(f"||x|| = √{norm_x ** 2}")

# (3) ||y|| norm 노름
norm_y = np.linalg.norm(y)
print(f"||y|| = √{norm_y ** 2}")

<x, y> = 7
||x|| = √22.0
||y|| = √15.000000000000002

퀴즈 2. 내적의 선형성#

문제는 다음 조건에서 $\langle 2v_1 - 3v_2, w \rangle$을 계산하는 것이다.

$$v_1, v_2, w \in R^n$$

$$\langle v_1, w \rangle = 3, \quad \langle v_2, w \rangle = -2$$

내적은 선형성을 가지므로 다음처럼 분배할 수 있다.

$$\langle 2v_1 - 3v_2, w \rangle = 2\langle v_1, w \rangle - 3\langle v_2, w \rangle$$

값을 대입하면 다음과 같다.

$$2 \cdot 3 - 3 \cdot (-2) = 6 + 6 = 12$$

정답은 $12$이다.

# 임의의 벡터로 검증
v1 = np.array([1, 0, 0])
v2 = np.array([0, 1, 0])
w = np.array([3, -2, 0])

# 조건 확인
print(f"<v1, w> = {np.dot(v1, w)}") # 3
print(f"<v2, w> = {np.dot(v2, w)}") # -2

# 문제 풀이
result = np.dot(2*v1 - 3*v2, w)
print(f"\n<2v1 - 3v2, w> = {result}")

# 분배법칙으로 검증
result_dist = 2 * np.dot(v1, w) - 3 * np.dot(v2, w)
print(f"\n2 <v1, w> - 3 <v2, w> = {result_dist}")

<v1, w> = 3
<v2, w> = -2

<2v1 - 3v2, w> = 12

2 <v1, w> - 3 <v2, w> = 12

퀴즈 3. 2x2 행렬 곱셈#

다음 두 행렬을 곱한다.

$$A = \begin{pmatrix} 3 & 1 \\ 2 & 1 \end{pmatrix} \begin{pmatrix} 1 & -1 \\ -2 & 3 \end{pmatrix}$$

행렬 곱셈은 왼쪽 행과 오른쪽 열의 내적으로 계산한다.

$$\begin{pmatrix} 3 & 1 \\ 2 & 1 \end{pmatrix} \begin{pmatrix} 1 & -1 \\ -2 & 3 \end{pmatrix} = \begin{pmatrix} 3 \cdot 1 + 1 \cdot (-2) & 3 \cdot (-1) + 1 \cdot 3 \\ 2 \cdot 1 + 1 \cdot (-2) & 2 \cdot (-1) + 1 \cdot 3 \end{pmatrix}$$

계산 결과는 단위행렬이다.

$$A = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$$

import numpy as np

B = np.array([[3, 1], [2, 1]])
C = np.array([[1, -1], [-2, 3]])

# 행렬 곱셈
result = np.dot(B, C)
print(f"A = \n{result}")

A =
[[1 0]
 [0 1]]

퀴즈 4. 3x2 행렬과 2x3 행렬의 곱#

이번에는 $(3 \times 2)$ 행렬과 $(2 \times 3)$ 행렬을 곱한다. 결과 행렬의 크기는 $(3 \times 3)$이다.

$$A = \begin{pmatrix} -1 & 2 \\ -2 & 1 \\ 3 & 4 \end{pmatrix} \begin{pmatrix} 1 & 0 & 2 \\ 2 & -3 & 1 \end{pmatrix}$$

각 위치는 행과 열의 내적으로 계산한다.

$$A = \begin{pmatrix} 3 & -6 & 0 \\ 0 & -3 & -3 \\ 11 & -12 & 10 \end{pmatrix}$$

import numpy as np

B = np.array([[-1, 2], [-2, 1], [3, 4]])
C = np.array([[1, 0, 2], [2, -3, 1]])

# A = np.dot(B, C)
A = B @ C # 행렬곱, 위와 동일 코드

print(f"A = \n{A}")

A =
[[  3  -6   0]
 [  0  -3  -3]
 [ 11 -12  10]]

행렬 곱셈에서 기억할 점은 다음과 같다.

  • $A$가 $m \times r$, $B$가 $r \times n$일 때만 $AB$가 가능하다.
  • 결과 행렬의 크기는 $m \times n$이다.
  • 일반적으로 $AB \neq BA$이므로 교환법칙이 성립하지 않는다.
  • 두 행렬의 곱이 단위행렬이면 서로 역행렬 관계이다.

퀴즈 5. 연립방정식과 Gauss 소거법#

다음 연립방정식의 해를 구한다.

$$\begin{cases} x + 2y - 4z = 2 \\ x + 3y - 6z = 1 \\ x + 2y - 3z = 4 \end{cases}$$

첨가행렬을 만들면 다음과 같다.

$$\left[\begin{array}{ccc|c} 1 & 2 & -4 & 2 \\ 1 & 3 & -6 & 1 \\ 1 & 2 & -3 & 4 \end{array}\right]$$

$R_2 \leftarrow R_2 - R_1$, $R_3 \leftarrow R_3 - R_1$을 적용하면 상삼각행렬 형태가 된다.

$$\left[\begin{array}{ccc|c} 1 & 2 & -4 & 2 \\ 0 & 1 & -2 & -1 \\ 0 & 0 & 1 & 2 \end{array}\right]$$

후진 대입으로 계산하면 다음과 같다.

$$z = 2$$

$$y - 2z = -1 \Rightarrow y - 4 = -1 \Rightarrow y = 3$$

$$x + 2y - 4z = 2 \Rightarrow x + 6 - 8 = 2 \Rightarrow x = 4$$

정답은 다음과 같다.

$$x = 4, \quad y = 3, \quad z = 2$$

import numpy as np

A = np.array([
    [1, 2, -4],
    [1, 3, -6],
    [1, 2, -3]
])

b = np.array([2, 1, 4])

solution = np.linalg.solve(A, b)
print(solution)

# 검증
print(f"\n검증: A @ x = {A @ solution}")
print(f"정답 b = {b}")

[4. 3. 2.]

검증: A @ x = [2. 1. 4.]
정답 b = [2 1 4]

Gauss 소거법과 Gauss-Jordan 소거법 비교#

구분 Gauss 소거법 Gauss-Jordan 소거법
목표 행렬 상삼각행렬 단위행렬(RREF)
해 구하는 방법 후진 대입법 필요 직접 읽어냄
행 연산 횟수 상대적으로 적음 상대적으로 많음
핵심 아이디어 아래쪽 계수를 0으로 만듦 위아래 계수를 모두 0으로 만듦

Gauss 소거법은 계산량이 비교적 적고, Gauss-Jordan 소거법은 결과 행렬에서 해를 바로 읽을 수 있다는 장점이 있다.

import numpy as np

A = np.array([
    [1, 2, -4],
    [1, 3, -6],
    [1, 2, -3]
], dtype=float)

b = np.array([2, 1, 4], dtype=float)

def gauss_elimination(A, b):
    n = len(b)
    Aug = np.hstack([A.copy(), b.copy().reshape(-1, 1)])
    print("=" * 50)
    print("[ Gauss 소거법 ]")
    print("=" * 50)
    print(f"\n[초기] 첨가행렬:\n{Aug}\n")

    for i in range(n):
        for j in range(i+1, n):
            factor = Aug[j, i] / Aug[i, i]
            Aug[j] = Aug[j] - factor * Aug[i]
            print(f"R{j+1} ← R{j+1} - {factor:.0f}×R{i+1}")
            print(f"{Aug}\n")

    print(f"[상삼각행렬 완성]:\n{Aug}\n")

    x = np.zeros(n)
    for i in range(n-1, -1, -1):
        x[i] = (Aug[i, -1] - np.dot(Aug[i, i+1:n], x[i+1:n])) / Aug[i, i]
        print(f"x{i+1} = {x[i]:.0f}")

    return x

def gauss_jordan(A, b):
    n = len(b)
    Aug = np.hstack([A.copy(), b.copy().reshape(-1, 1)])
    print("\n" + "=" * 50)
    print("[ Gauss-Jordan 소거법 ]")
    print("=" * 50)
    print(f"\n[초기] 첨가행렬:\n{Aug}\n")

    for i in range(n):
        Aug[i] = Aug[i] / Aug[i, i]
        for j in range(n):
            if j != i:
                factor = Aug[j, i]
                Aug[j] = Aug[j] - factor * Aug[i]
                print(f"R{j+1} ← R{j+1} - {factor:.0f}×R{i+1}")
                print(f"{Aug}\n")

    print(f"[단위행렬(RREF) 완성]:\n{Aug}\n")
    return Aug[:, -1]

x1 = gauss_elimination(A, b)
x2 = gauss_jordan(A, b)
x3 = np.linalg.solve(A, b)

print("\n" + "=" * 50)
print("[ 최종 결과 비교 ]")
print("=" * 50)
print(f"Gauss 소거법        : x={x1[0]:.0f}, y={x1[1]:.0f}, z={x1[2]:.0f}")
print(f"Gauss-Jordan 소거법 : x={x2[0]:.0f}, y={x2[1]:.0f}, z={x2[2]:.0f}")
print(f"numpy.linalg.solve  : x={x3[0]:.0f}, y={x3[1]:.0f}, z={x3[2]:.0f}")

비즈니스 관점에서 보는 선형방정식#

선형방정식은 비즈니스 제약 조건 속에서 최적의 해답을 찾는 문제로 해석할 수 있다. 예를 들어 광고 채널 A와 B의 집행 횟수를 정한다고 가정한다.

  • 광고 채널 A 집행 횟수: $x$
  • 광고 채널 B 집행 횟수: $y$
  • 예산 제약: $3x + y = 9$
  • 시간 제약: $x + 2y = 8$

행렬로 쓰면 다음과 같다.

$$\begin{pmatrix} 3 & 1 \\ 1 & 2 \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 9 \\ 8 \end{pmatrix}$$

이를 풀면 $x=2$, $y=3$이다. 즉 광고 채널 A에 2회, 광고 채널 B에 3회 집행하는 지점이 두 제약 조건을 동시에 만족한다.

# 선형방정식 행렬 세팅(Ax = b)
A_matrix = np.array([
    [3, 1],
    [1, 2]
])

b_vector = np.array([9, 8])

solution = np.linalg.solve(A_matrix, b_vector)
x_sol, y_sol = solution
print(x_sol, y_sol)

2.0 3.0

import numpy as np
import matplotlib.pyplot as plt

A_matrix = np.array([
    [3, 1],
    [1, 2]

solution = np.linalg.solve(A_matrix, b_vector)
x_sol, y_sol = solution
print(x_sol, y_sol)

x_vals = np.linspace(0, 5, 100)

ax.scatter(x_sol, y_sol, color='#333333', s=120, zorder=5)
ax.annotate(f'Optimal Allocation\n(Channel A={x_sol:.1f}, Channel B={y_sol:.1f})',
            xy=(x_sol, y_sol),
            xytext=(x_sol + 0.3, y_sol + 1.5),
            fontsize=10,

ax.set_xlim(0, 4)

제약 조건 변경 시나리오#

기존 조건은 예산 9, 시간 8이었다. 시나리오를 바꿔 예산은 12로 늘고 시간은 7로 줄어든다고 가정한다.

$$3x + y = 12$$

$$x + 2y = 7$$

계수 행렬은 동일하고 상수 벡터만 바뀐다.

A_matrix = np.array([
    [3, 1],
    [1, 2]
])

b_old = np.array([9, 8])
b_new = np.array([12, 7])

old_solution = np.linalg.solve(A_matrix, b_old)
new_solution = np.linalg.solve(A_matrix, b_new)

print(f"기존 최적해: A={old_solution[0]:.1f}, B={old_solution[1]:.1f}")
print(f"새 최적해: A={new_solution[0]:.1f}, B={new_solution[1]:.1f}")

기존 최적해: A=2.0, B=3.0
새 최적해: A=3.4, B=1.8

정리#

이번 퀴즈에서 확인한 핵심은 다음과 같다.

  • 내적은 두 벡터가 같은 방향으로 얼마나 맞물리는지 계산하는 연산이다.
  • 노름은 벡터의 크기를 의미한다.
  • 행렬 곱셈은 행과 열의 내적이며, 차원 조건이 맞아야 계산할 수 있다.
  • 연립방정식은 행렬 $Ax=b$로 표현할 수 있다.
  • Gauss 소거법과 Gauss-Jordan 소거법은 첨가행렬을 변형해 해를 찾는 방법이다.
