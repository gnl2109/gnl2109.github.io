    Pandas 시계열 50제: 문제 11~20#

    문제 11~20은 Pandas의 .dt 접근자를 사용해서 날짜/시간 컬럼에서 필요한 구성 요소를 뽑아내는 연습이다.

    Series가 datetime64[ns] 타입이면 .dt.year, .dt.month, .dt.day_name()처럼 날짜 전용 기능을 사용할 수 있다.

    공통 준비 코드#

    import pandas as pd
import numpy as np
import datetime

pd.set_option("display.max_columns", 15)
pd.set_option("display.width", 110)

    원본 노트북에서는 Classic Models 샘플 CSV를 불러오면서 날짜 컬럼을 datetime 타입으로 변환했다.

    DATA = "/content/drive/MyDrive/Colab Notebooks/2026/이어드림스쿨6기/dataset/erd_sample"

orders = pd.read_csv(
    f"{DATA}/orders.csv",
    parse_dates=["orderDate", "requiredDate", "shippedDate"]
)

payments = pd.read_csv(
    f"{DATA}/payments.csv",
    parse_dates=["paymentDate"]
)

    parse_dates를 사용하지 않았다면 .dt 접근자를 쓰기 전에 pd.to_datetime()으로 변환해야 한다.

    orders["orderDate"] = pd.to_datetime(orders["orderDate"])
payments["paymentDate"] = pd.to_datetime(payments["paymentDate"])

    Q11. .dt.year, .dt.month, .dt.day 추출#

    날짜 컬럼에서 연도, 월, 일을 각각 새로운 컬럼으로 분리할 수 있다.

    orders["year"] = orders["orderDate"].dt.year
orders["month"] = orders["orderDate"].dt.month
orders["day"] = orders["orderDate"].dt.day

orders[["orderDate", "year", "month", "day"]].head()

       orderDate  year  month  day
0 2003-01-06  2003      1    6
1 2003-01-09  2003      1    9
2 2003-01-10  2003      1   10
3 2003-01-29  2003      1   29
4 2003-01-31  2003      1   31

    이렇게 분리해두면 연도별, 월별 집계가 쉬워진다.

    Q12. .dt.hour, .dt.minute, .dt.second 추출#

    시분초가 포함된 datetime 데이터에서는 시간, 분, 초도 각각 꺼낼 수 있다.

    ts_series = pd.Series(
    pd.date_range("2003-01-06 09:05:30", periods=5, freq="90min")
)

print(ts_series)
print("hour:", ts_series.dt.hour.tolist())
print("minute:", ts_series.dt.minute.tolist())
print("second:", ts_series.dt.second.tolist())

    0   2003-01-06 09:05:30
1   2003-01-06 10:35:30
2   2003-01-06 12:05:30
3   2003-01-06 13:35:30
4   2003-01-06 15:05:30
dtype: datetime64[ns]
hour: [9, 10, 12, 13, 15]
minute: [5, 35, 5, 35, 5]
second: [30, 30, 30, 30, 30]

    freq="90min"은 90분 간격으로 날짜/시간을 생성한다.

    Q13. .dt.day_name()으로 요일 이름 추출#

    day_name()을 사용하면 날짜의 요일을 문자열로 얻을 수 있다.

    orders["weekday"] = orders["orderDate"].dt.day_name()

orders[["orderDate", "weekday"]].head()

       orderDate    weekday
0 2003-01-06     Monday
1 2003-01-09   Thursday
2 2003-01-10     Friday
3 2003-01-29  Wednesday
4 2003-01-31     Friday

    요일별 주문 수를 보고 싶다면 value_counts()를 붙이면 된다.

    orders["weekday"].value_counts()

    Q14. .dt.dayofweek로 요일 번호 추출#

    dayofweek는 요일을 숫자로 반환한다. 월요일은 0, 일요일은 6이다.

    orders["dow"] = orders["orderDate"].dt.dayofweek

# 토요일=5, 일요일=6
orders["is_weekend"] = orders["dow"] >= 5

orders[["orderDate", "weekday", "dow", "is_weekend"]].head()

       orderDate    weekday  dow  is_weekend
0 2003-01-06     Monday    0       False
1 2003-01-09   Thursday    3       False
2 2003-01-10     Friday    4       False
3 2003-01-29  Wednesday    2       False
4 2003-01-31     Friday    4       False

    주말 여부처럼 조건 컬럼을 만들 때는 요일 이름보다 숫자 요일이 더 편하다.

    Q15. .dt.quarter로 분기 추출#

    quarter는 날짜가 몇 분기에 속하는지 1~4 사이의 숫자로 반환한다.

    orders["quarter"] = orders["orderDate"].dt.quarter

orders.groupby("quarter")["orderNumber"].count()

    quarter
1    ...
2    ...
3    ...
4    ...
Name: orderNumber, dtype: int64

    분기별 주문량, 매출, 결제 금액 등을 집계할 때 자주 쓰인다.

    Q16. .dt.isocalendar()로 ISO 주 번호 추출#

    Pandas에서는 .dt.isocalendar()를 사용해 ISO 기준 연도, 주차, 요일 번호를 얻을 수 있다.

    iso = orders["orderDate"].dt.isocalendar()

orders["iso_year"] = iso["year"]
orders["iso_week"] = iso["week"]
orders["iso_day"] = iso["day"]

orders[["orderDate", "iso_year", "iso_week", "iso_day"]].head()

       orderDate  iso_year  iso_week  iso_day
0 2003-01-06      2003         2        1
1 2003-01-09      2003         2        4
2 2003-01-10      2003         2        5
3 2003-01-29      2003         5        3
4 2003-01-31      2003         5        5

    ISO 기준에서 월요일은 1, 일요일은 7이다. 앞의 dayofweek와 번호 체계가 다르므로 헷갈리지 않도록 주의해야 한다.

    Q17. .dt.days_in_month로 해당 월의 총 일수 확인#

    days_in_month는 해당 날짜가 속한 월이 며칠까지 있는지 알려준다.

    payments["payment_day"] = payments["paymentDate"].dt.day
payments["days_in_month"] = payments["paymentDate"].dt.days_in_month

payments[["paymentDate", "payment_day", "days_in_month"]].head()

      paymentDate  payment_day  days_in_month
0  2004-10-19           19             31
1  2003-06-05            5             30
2  2004-12-18           18             31
3  2004-12-17           17             31
4  2003-05-20           20             31

    월마다 마지막 날짜가 다르기 때문에 월말 여부를 확인할 때 유용하다.

    payments["is_last_day"] = (
    payments["paymentDate"].dt.day == payments["paymentDate"].dt.days_in_month
)

payments[["paymentDate", "days_in_month", "is_last_day"]].head()

    Q18. .dt.normalize()로 시간 초기화#

    normalize()는 날짜는 유지하고 시간 부분을 00:00:00으로 초기화한다.

    ts_series = pd.Series(
    pd.date_range("2003-01-06 09:05:30", periods=4, freq="90min")
)

print("원본:")
print(ts_series)

print("\nnormalize (시간 제거):")
print(ts_series.dt.normalize())

    원본:
0   2003-01-06 09:05:30
1   2003-01-06 10:35:30
2   2003-01-06 12:05:30
3   2003-01-06 13:35:30
dtype: datetime64[ns]

normalize (시간 제거):
0   2003-01-06
1   2003-01-06
2   2003-01-06
3   2003-01-06
dtype: datetime64[ns]

    시각 차이는 무시하고 날짜 단위로만 비교하거나 병합할 때 사용할 수 있다.

    Q19. .dt.strftime()으로 날짜를 문자열 포맷으로 변환#

    strftime()은 datetime 값을 원하는 문자열 형식으로 바꾼다.

    orders["date_str_kr"] = orders["orderDate"].dt.strftime("%Y년 %m월 %d일")
orders["date_str_us"] = orders["orderDate"].dt.strftime("%B %d %Y")

orders[["orderDate", "date_str_kr", "date_str_us"]].head()

       orderDate  date_str_kr      date_str_us
0 2003-01-06  2003년 01월 06일  January 06 2003
1 2003-01-09  2003년 01월 09일  January 09 2003
2 2003-01-10  2003년 01월 10일  January 10 2003
3 2003-01-29  2003년 01월 29일  January 29 2003
4 2003-01-31  2003년 01월 31일  January 31 2003

    자주 쓰는 포맷 코드는 다음과 같다.

    • %Y : 4자리 연도
    • %m : 2자리 월
    • %d : 2자리 일
    • %B : 영어 월 이름
    • %H : 24시간 기준 시
    • %M : 분
    • %S : 초

    Q20. .dt.to_period()로 Timestamp를 Period로 변환#

    원본 노트북의 Q20 코드 셀은 비어 있었지만, 제목에 맞춰 Timestamp를 Period로 변환하는 예제로 정리한다.

    Timestamp가 특정 시점을 의미한다면, Period는 월/분기/연도 같은 기간을 의미한다.

    # 월 단위 Period
orders["order_month"] = orders["orderDate"].dt.to_period("M")

# 분기 단위 Period
orders["order_quarter"] = orders["orderDate"].dt.to_period("Q")

orders[["orderDate", "order_month", "order_quarter"]].head()

       orderDate order_month order_quarter
0 2003-01-06     2003-01        2003Q1
1 2003-01-09     2003-01        2003Q1
2 2003-01-10     2003-01        2003Q1
3 2003-01-29     2003-01        2003Q1
4 2003-01-31     2003-01        2003Q1

    월별 주문 수를 집계할 때는 다음처럼 사용할 수 있다.

    monthly_orders = orders.groupby("order_month")["orderNumber"].count()
monthly_orders.head()

    to_period("M")로 월 단위 기간 컬럼을 만들어두면 날짜가 서로 달라도 같은 월끼리 자연스럽게 묶을 수 있다.

    정리#

    문제 11~20은 datetime 컬럼에서 분석용 파생변수를 만드는 연습이다.

    • 연/월/일 추출: .dt.year, .dt.month, .dt.day
    • 시/분/초 추출: .dt.hour, .dt.minute, .dt.second
    • 요일 추출: .dt.day_name(), .dt.dayofweek
    • 분기 추출: .dt.quarter
    • ISO 주차 추출: .dt.isocalendar()
    • 월 일수 확인: .dt.days_in_month
    • 시간 초기화: .dt.normalize()
    • 문자열 포맷 변환: .dt.strftime()
    • 기간 단위 변환: .dt.to_period()

    시계열 데이터를 다룰 때는 원본 날짜 컬럼 하나에서 여러 분석 기준을 뽑아내는 일이 많다. .dt 접근자는 그 작업을 가장 간단하게 해주는 도구다.
