    Seaborn#

    Seaborn은 Matplotlib 위에 색 테마와 통계 차트 기능을 더한 데이터 시각화 라이브러리다.

    Matplotlib이 그래프를 세밀하게 제어하는 기본 도구라면, Seaborn은 데이터 분석에서 자주 쓰는 통계 그래프를 더 간결하고 보기 좋게 그릴 수 있도록 도와준다.

    • Matplotlib 기반으로 동작한다.
    • 산점도, 회귀선, 범주형 빈도, 분포 시각화에 편리하다.
    • 기본 스타일이 정돈되어 있어 EDA에 많이 사용한다.
    • DataFrame 컬럼명을 바로 지정해서 그래프를 그릴 수 있다.
    • 내장 예제 데이터셋을 제공한다.

    Seaborn import#

    Seaborn은 관례적으로 sns라는 별칭으로 불러온다.

    import seaborn as sns
import matplotlib.pyplot as plt

print("Seaborn version:", sns.__version__)

    Seaborn version: 0.13.2

    그래프 출력에는 Matplotlib의 plt.show()를 함께 사용한다.

    4-1. 데이터 로드와 regplot()#

    Seaborn은 sns.load_dataset()으로 내장 예제 데이터를 불러올 수 있다. 여기서는 머신러닝 입문에서 자주 사용하는 iris 데이터셋을 사용한다.

    df = sns.load_dataset("iris")

    regplot()은 산점도와 회귀선을 함께 그린다.

    • x, y: 축으로 사용할 컬럼
    • data: 사용할 DataFrame
    • color: 전체 그래프 색상
    • line_kws: 회귀선 속성
    • scatter_kws: 산점도 점 속성
    • ax: 그래프를 그릴 Matplotlib axes
    fig, ax = plt.subplots(nrows=2, ncols=2)

# 기본 시각화
sns.regplot(
    data=df,
    x="sepal_length",
    y="petal_length",
    ax=ax[0, 0]
)
ax[0, 0].set_title("Sepal Length vs Petal Length")

# 회귀선 색상 변경
sns.regplot(
    data=df,
    x="sepal_length",
    y="petal_length",
    ax=ax[0, 1],
    line_kws={"color": "red"}
)
ax[0, 1].set_title("Line Color Changed to Red")

# 산점도 색상 변경
sns.regplot(
    data=df,
    x="sepal_length",
    y="petal_length",
    ax=ax[1, 0],
    line_kws={"color": "red"},
    scatter_kws={"color": "green"}
)
ax[1, 0].set_title("Scatter Color Changed to Green")

plt.tight_layout()
plt.show()

    기본 regplot() 하나만 그리면 다음과 같다.

    sns.regplot(x="sepal_length", y="petal_length", data=df)
plt.title("Sepal Length vs Petal Length")
plt.show()

    회귀선 색상은 line_kws로 바꿀 수 있다.

    sns.regplot(
    x="sepal_length",
    y="petal_length",
    data=df,
    line_kws={"color": "red"}
)
plt.title("Regression Line Color Changed to Red")
plt.show()

    산점도 점의 색상과 투명도는 scatter_kws로 조정한다.

    sns.regplot(
    x="sepal_length",
    y="petal_length",
    data=df,
    scatter_kws={"color": "green", "alpha": 0.5}
)
plt.title("Scatter Points Color Changed to Green")
plt.show()

    regplot()은 두 연속형 변수 사이에 대략적인 선형 관계가 있는지 빠르게 확인할 때 유용하다.

    4-2. countplot()과 jointplot()#

    countplot()은 범주형 데이터의 빈도를 막대 그래프로 보여준다.

    • x: 빈도를 셀 범주형 변수
    • hue: 추가로 색을 나눌 기준 변수
    • data: 사용할 DataFrame

    타이타닉 데이터셋을 불러와 승객 등급별 빈도를 확인해본다.

    titanic = sns.load_dataset("titanic")

print("Titanic dataset - first 5 rows:")

    Matplotlib의 subplots()와 Seaborn을 함께 사용할 수도 있다. 아래 예제는 3행 3열 중 정가운데 axes에만 countplot을 그린다.

    fig, ax = plt.subplots(nrows=3, ncols=3)

sns.countplot(data=titanic, x="class", ax=ax[1, 1])

plt.tight_layout()
plt.show()

    일반적인 승객 등급별 빈도 그래프는 다음처럼 그릴 수 있다.

    sns.countplot(x="class", data=titanic)
plt.title("Passenger Count by Class")
plt.show()

    hue를 사용하면 같은 x축 범주 안에서 추가 기준으로 색을 나눌 수 있다.

    sns.countplot(x="class", hue="survived", data=titanic)
plt.title("Passenger Count by Class and Survival")
plt.legend(["Not Survived (0)", "Survived (1)"])
plt.show()

    이 그래프를 보면 승객 등급별 인원 차이뿐 아니라 생존 여부의 분포도 함께 비교할 수 있다.

    jointplot()으로 산점도와 분포 함께 보기#

    jointplot()은 두 변수의 관계와 각 변수의 분포를 한 번에 보여준다.

    • x, y: 축으로 사용할 컬럼
    • data: 사용할 DataFrame
    • kind: 그래프 종류
    • kind="scatter": 기본 산점도
    • kind="reg": 산점도와 회귀선
    • kind="resid": 잔차 플롯
    • kind="kde": 커널 밀도 추정

    tips 데이터셋을 불러와 총 결제 금액과 팁의 관계를 확인한다.

    tips = sns.load_dataset("tips")

print("Tips dataset - first 5 rows:")
tips.head()

       total_bill   tip     sex smoker  day    time  size
0       16.99  1.01  Female     No  Sun  Dinner     2
1       10.34  1.66    Male     No  Sun  Dinner     3
2       21.01  3.50    Male     No  Sun  Dinner     3
3       23.68  3.31    Male     No  Sun  Dinner     2
4       24.59  3.61  Female     No  Sun  Dinner     4

    sns.jointplot(
    x="total_bill",
    y="tip",
    data=tips,
    kind="scatter"
)
plt.show()

    회귀선을 함께 보고 싶다면 kind="reg"를 사용한다.

    sns.jointplot(
    x="total_bill",
    y="tip",
    data=tips,
    kind="reg"
)
plt.show()

    jointplot()은 중앙에는 두 변수의 관계를, 위와 오른쪽에는 각 변수의 단변량 분포를 함께 보여주기 때문에 EDA에서 유용하다.

    정리#

    Seaborn Part 4에서 익힌 핵심은 Matplotlib보다 간결하게 통계 그래프를 그리는 방법이다.

    • Seaborn import: import seaborn as sns
    • 내장 데이터셋 로드: sns.load_dataset()
    • 산점도 + 회귀선: sns.regplot()
    • 범주형 빈도 그래프: sns.countplot()
    • 색상 기준 추가: hue
    • 산점도 + 주변 분포: sns.jointplot()
    • Matplotlib axes와 연결: ax=...

    Seaborn은 Pandas DataFrame과 잘 맞기 때문에, 데이터 탐색 단계에서 변수 간 관계와 범주별 차이를 빠르게 확인하기 좋다.
