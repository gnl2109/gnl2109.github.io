3. DB와 SQL#

  • DB
    • 관계형 데이터베이스(RDB)
    • Redis 와 같은 데이터베이스 형식도 참고
    • 데이터 정규화 : 1NF, 2NF, 3NF 개념 알기
      • 1NF : 한 칸에 하나의 값. 반복되는 그룹 제거. 원자값 유지
      • 2NF : 기본키 일부에만 의존하는 컬럼 분리. 부분 함수 종속 제거
      • 3NF : 일반 컬럼끼리 의존하는 컬럼 분리. 이행 함수 종속 제거
    • 데이터 정규화의 이유 : 데이터 무결성
  • SQL
    • INNER JOIN, LEFT OUTER JOIN, RIGHT OUTER JOIN, CROSS JOIN
    • JOIN 옵션 : ON, USING, NATURAL
    • 다중행 연산자 : IN, ANY, ALL, EXISTS
    • 윈도우 함수 : RANK () OVER(PARTITION BY 컬럼 ORDER BY 컬럼 DESC)
