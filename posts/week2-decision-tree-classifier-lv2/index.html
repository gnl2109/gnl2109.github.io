데이터 분류 모델 DecisionTreeClassifier Lv2#

이번 글은 0702 Lv1 예제에서 확장된 Titanic 생존 여부 분류 모델이다.

Lv1에서는 pclass, fare 두 개의 수치형 변수만 사용했다. Lv2에서는 여기에 age, embarked를 추가한다.

  • 독립변수 X: pclass, fare, age, embarked
  • 종속변수 y: survived (0=사망, 1=생존)
  • 새로 추가된 전처리: SimpleImputer, OneHotEncoder, ColumnTransformer
  • 모델: DecisionTreeClassifier

데이터 로드, 학습/테스트 분리, fit(), predict(), 평가 지표 계산 흐름은 Lv1과 같으므로 코드 위주로 정리한다. 이번 글에서는 결측치 처리, 범주형 데이터 인코딩, 컬럼별 전처리 분기를 중심으로 보면 된다.

환경 설정#

import seaborn as sns
import pandas as pd
import numpy as np

from sklearn.model_selection import train_test_split
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

Lv2에서 새로 등장한 도구는 다음과 같다.

  • SimpleImputer: 결측치(NaN)를 특정 규칙으로 채운다.
  • OneHotEncoder: 문자형 범주 데이터를 숫자 0/1 컬럼으로 변환한다.
  • ColumnTransformer: 컬럼 종류별로 서로 다른 전처리를 적용한다.

추가 개념 1. 결측치 처리#

Lv2에서는 age와 embarked에 결측치가 있다.

  • age: 177개 결측치
  • embarked: 2개 결측치

머신러닝 모델은 일반적으로 NaN이 포함된 데이터를 그대로 학습하기 어렵다. 그래서 결측치를 먼저 채워야 한다.

수치형 데이터와 범주형 데이터는 결측치를 채우는 방식이 다르다.

  • 수치형 age: 중앙값(median)으로 채움
  • 범주형 embarked: 최빈값(most_frequent)으로 채움
numeric_transformer = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler())
])

categorical_transformer = Pipeline([
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("onehot", OneHotEncoder(handle_unknown="ignore"))
])

median은 평균보다 이상치의 영향을 덜 받기 때문에 나이처럼 분포가 치우칠 수 있는 데이터에 자주 사용한다.

most_frequent는 가장 많이 등장한 값으로 결측치를 채운다. embarked처럼 선택지가 정해진 범주형 데이터에 사용할 수 있다.

추가 개념 2. 범주형 데이터 인코딩#

embarked는 탑승 항구를 나타내는 문자형 데이터다.

  • C: Cherbourg
  • Q: Queenstown
  • S: Southampton

하지만 머신러닝 모델은 문자열을 그대로 계산할 수 없다. 그래서 OneHotEncoder를 사용해 문자 범주를 0과 1로 바꾼다.

예를 들어 embarked가 다음과 같이 변환된다.

embarked = C  ->  embarked_C=1, embarked_Q=0, embarked_S=0
embarked = Q  ->  embarked_C=0, embarked_Q=1, embarked_S=0
embarked = S  ->  embarked_C=0, embarked_Q=0, embarked_S=1

handle_unknown="ignore"는 테스트 데이터나 사용자 입력에 학습 때 보지 못한 범주가 들어와도 오류를 내지 않도록 하는 옵션이다.

추가 개념 3. ColumnTransformer#

Lv1에서는 모든 입력 변수가 수치형이었기 때문에 StandardScaler만 적용하면 됐다. 하지만 Lv2는 수치형과 범주형이 섞여 있다.

  • 수치형: pclass, fare, age
  • 범주형: embarked

이럴 때 ColumnTransformer를 사용하면 컬럼별로 다른 전처리 파이프라인을 적용할 수 있다.

numeric_features = ["pclass", "fare", "age"]
categorical_features = ["embarked"]

preprocessor = ColumnTransformer([
    ("num", numeric_transformer, numeric_features),
    ("cat", categorical_transformer, categorical_features)
])

이 코드는 다음 의미다.

  • pclass, fare, age에는 numeric_transformer 적용
  • embarked에는 categorical_transformer 적용

즉, 하나의 입력 데이터 안에서 컬럼 성격에 맞는 전처리를 나눠서 처리한다.

Pipeline 정의#

pipeline = Pipeline([
    ("preprocessor", preprocessor),
    ("model", DecisionTreeClassifier(random_state=42))
])

pipeline

전체 흐름은 다음과 같다.

  1. ColumnTransformer가 컬럼별 전처리를 수행한다.
  2. 수치형 컬럼은 결측치 채우기 후 스케일링한다.
  3. 범주형 컬럼은 결측치 채우기 후 원-핫 인코딩한다.
  4. 전처리된 데이터를 DecisionTreeClassifier에 전달한다.

모델 학습#

pipeline.fit(X_train, y_train)

예측 및 평가#

y_pred = pipeline.predict(X_test)

accuracy = accuracy_score(y_test, y_pred)
precision = precision_score(y_test, y_pred)
recall = recall_score(y_test, y_pred)
f1 = f1_score(y_test, y_pred)

print("--- 테스트 데이터 평가 결과 ---")
print(f"Accuracy  (정확도)        : {accuracy:.4f}")
print(f"Precision (정밀도)        : {precision:.4f}")
print(f"Recall    (재현율)        : {recall:.4f}")
print(f"F1 score  (F1 점수)       : {f1:.4f}")

변수를 더 추가했다고 해서 항상 성능이 좋아지는 것은 아니다. 새 변수가 예측에 도움이 될 수도 있지만, 모델 구조나 데이터 분할, 결측치 처리 방식, 하이퍼파라미터에 따라 성능이 오히려 낮아질 수도 있다.

이번 Lv2의 핵심은 점수 향상 자체보다 현실적인 데이터 전처리 구조를 만들었다는 점이다. 실제 데이터에는 결측치와 문자형 컬럼이 자주 포함되기 때문에, SimpleImputer, OneHotEncoder, ColumnTransformer를 함께 쓰는 패턴이 중요하다.

사용자 입력 테스트#

pclass = float(input("객실 등급(pclass, 1~3)을 입력하세요: "))
fare = float(input("요금(fare)을 입력하세요: "))
age = float(input("나이(age)를 입력하세요: "))
embarked = input("탑승 항구(embarked: C / Q / S)를 입력하세요: ")

user_input = pd.DataFrame(
    [[pclass, fare, age, embarked]],
    columns=["pclass", "fare", "age", "embarked"]
)
predicted = int(pipeline.predict(user_input)[0])

label = "생존" if predicted == 1 else "사망"
print(f"\n예측 결과(survived): {predicted} ({label})")

객실 등급(pclass, 1~3)을 입력하세요: 1
요금(fare)을 입력하세요: 20
나이(age)를 입력하세요: 10
탑승 항구(embarked: C / Q / S)를 입력하세요: C

예측 결과(survived): 1 (생존)

사용자 입력 데이터도 학습 데이터와 같은 컬럼 구조를 가져야 한다.

columns=["pclass", "fare", "age", "embarked"]

이 컬럼명이 ColumnTransformer에서 지정한 컬럼명과 맞아야 전처리와 예측이 정상적으로 이어진다.

정리#

Lv2에서 새로 배운 핵심은 다음 세 가지다.

  • SimpleImputer로 결측치를 처리한다.
  • OneHotEncoder로 문자형 범주 데이터를 숫자형 데이터로 변환한다.
  • ColumnTransformer로 수치형 컬럼과 범주형 컬럼에 서로 다른 전처리를 적용한다.

Lv1이 기본적인 분류 모델 학습 흐름을 익히는 예제였다면, Lv2는 실제 데이터에 가까운 전처리 파이프라인을 구성하는 예제라고 볼 수 있다.
