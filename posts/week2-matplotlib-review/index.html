    Matplotlib#

    Matplotlib은 Python에서 가장 기본적으로 많이 사용하는 데이터 시각화 라이브러리다.

    데이터 시각화는 숫자나 표 형태의 데이터를 그래프, 차트 같은 시각 형태로 표현해 이해하기 쉽게 만드는 과정이다.

    • 정보 전달 효율을 높일 수 있다.
    • 데이터의 패턴과 상관관계를 파악하기 쉽다.
    • 여러 값이나 그룹을 비교하기 좋다.
    • 선 그래프, 산점도, 히스토그램, 막대 그래프 등을 세밀하게 제어할 수 있다.

    Matplotlib을 사용할 때는 보통 matplotlib.pyplot을 plt라는 이름으로 불러온다.

    import matplotlib.pyplot as plt
import matplotlib
import numpy as np

# Colab 또는 Jupyter Notebook 안에 그래프 표시
%matplotlib inline

print("Matplotlib version:", matplotlib.__version__)

    Matplotlib version: 3.x.x

    %matplotlib inline은 Jupyter/Colab 환경에서 그래프를 노트북 안에 바로 보여주기 위한 매직 명령어다. 일반 .py 파일에서는 사용하지 않는다.

    3-1. 기본 그래프: plot()#

    plot()은 데이터 점을 선으로 이어 선 그래프를 그리는 함수다.

    • x: x축 데이터
    • y: y축 데이터
    • fmt: 선 색, 마커, 선 스타일을 한 번에 지정하는 형식 문자열
    • xlabel(): x축 라벨
    • ylabel(): y축 라벨
    • title(): 그래프 제목
    • show(): 그래프 출력
    # 기본 선 그래프 예제
plt.plot(["Seoul", "Paris", "Seattle"], [30, 25, 55])

# 축 라벨과 제목
plt.xlabel("City")
plt.ylabel("Response")
plt.title("Experiment Result")

plt.show()

    plot(x, y) 형태로 작성하면 x축 값과 y축 값이 순서대로 매칭된다.

    형식 문자열을 사용하면 색, 마커, 선 스타일을 간단히 지정할 수 있다.

    x = [1, 2, 3, 4, 5]
y = [2, 4, 1, 5, 3]

# 'ro-' = red, circle marker, solid line
plt.plot(x, y, "ro-")
plt.xlabel("X values")
plt.ylabel("Y values")
plt.title("Line Graph with Format String")
plt.show()

    "ro-"는 빨간색 원 마커를 실선으로 연결하라는 의미다.

    3-2. 산점도: scatter()#

    scatter()는 점들을 선으로 연결하지 않고 흩뿌려서 보여주는 그래프다. 두 변수의 관계나 분포를 볼 때 자주 사용한다.

    • x, y: x축, y축 데이터
    • s: 점 크기
    • c: 점 색
    • marker: 점 모양
    • cmap: 컬러맵
    • alpha: 투명도
    # 기본 산점도
plt.scatter([1, 3, 2], [0, -1, 2])
plt.title("Basic Scatter Plot")
plt.show()

    점마다 크기와 색을 다르게 줄 수도 있다.

    np.random.seed(0)

x = np.random.randn(50)
y = np.random.randn(50)
colors = np.random.rand(50)
sizes = 100 * np.random.rand(50)

plt.scatter(
    x,
    y,
    s=sizes,
    c=colors,
    cmap="viridis",
    alpha=0.7,
    marker="o"
)
plt.colorbar(label="color value")
plt.title("Scatter Plot with Variable Size and Color")
plt.xlabel("X")
plt.ylabel("Y")
plt.show()

    대표적인 마커 모양은 다음과 같다.

    • ".": 작은 점
    • "o": 원
    • "v": 아래 삼각형
    • "s": 사각형
    • "x": x 모양

    3-3. 히스토그램: hist()#

    hist()는 연속형 데이터의 분포를 구간별 빈도로 보여준다.

    • x: 히스토그램을 그릴 데이터
    • bins: 구간 개수 또는 구간 경계

    히스토그램과 막대 그래프는 비슷해 보이지만 목적이 다르다.

    • 히스토그램: 연속형 데이터의 값 구간별 빈도 확인
    • 막대 그래프: 범주형 데이터의 범주별 값 비교
    data_list = [1, 3, 2, 2, 3, 3, 3, 1, 4, 8, 2, 6, 6]

plt.hist(data_list, bins=None)
plt.title("Histogram (bins=None, auto)")
plt.xlabel("Value")
plt.ylabel("Frequency")
plt.show()

    bins=None이면 Matplotlib이 적절한 구간 수를 자동으로 설정한다.

    구간 수를 직접 지정할 수도 있다.

    plt.hist(data_list, bins=2)
plt.title("Histogram (bins=2)")
plt.xlabel("Value")
plt.ylabel("Frequency")
plt.show()

    bins=2이면 전체 값을 두 구간으로 나누어 빈도를 계산한다.

    3-4. 막대 그래프: bar()#

    bar()는 범주별 값을 막대 높이로 표현한다.

    • x: 각 막대의 x축 위치 또는 범주 이름
    • height: 각 막대의 높이
    • width: 막대 너비
    plt.bar(["Seoul", "Paris", "Seattle"], [30, 25, 55])
plt.xlabel("City")
plt.ylabel("Response")
plt.title("Experiment Result - Bar Chart")
plt.show()

    도시별 응답값처럼 범주별 수치를 비교할 때는 선 그래프보다 막대 그래프가 더 직관적이다.

    3-5. 여러 그래프 출력#

    하나의 figure에 여러 그래프를 겹쳐 그릴 수 있다. 그래프 함수를 여러 번 호출하고 legend()로 범례를 추가하면 된다.

    plt.plot([1, 2, 3], [1, 4, 9])
plt.plot([2, 3, 4], [5, 6, 7])
plt.bar([1, 2, 4], [2, 3, 4])

plt.xlabel("Sequence")
plt.ylabel("Value")
plt.title("Multiple Graphs")
plt.legend(["Line1 (x^2)", "Line2 (Linear)", "Bar"])
plt.show()

    여러 그래프를 한 화면에 나눠서 배치하려면 subplot() 또는 subplots()를 사용한다.

    fig, ax = plt.subplots(nrows=2, ncols=2)

ax[1, 1].plot([1, 2, 3])
ax[1, 1].set_title("title1")

plt.show()

    plt.subplots(nrows=2, ncols=2)는 2행 2열의 그래프 공간을 만든다. ax[1, 1]은 두 번째 행, 두 번째 열의 좌표축을 의미한다.

    plt.subplot() 방식으로도 서브플롯을 만들 수 있다.

    np.random.seed(7)
x = np.random.rand(5)
y = np.random.rand(5)

# 서브플롯 1: 빨간 오른쪽 삼각형
plt.subplot(221)
plt.scatter(x, y, s=80, c="r", marker=">")
plt.title("Red Triangle")

# 서브플롯 2: 파란 오각형
plt.subplot(222)
plt.scatter(x, y, s=80, c="b", marker=(5, 0))
plt.title("Blue Pentagon")

# 서브플롯 3: 검은 사용자 정의 다각형
verts = np.array([[-1, -1], [1, -1], [1, 1], [-1, -1]])
plt.subplot(223)
plt.scatter(x, y, s=80, c="k", marker=verts)
plt.title("Black Polygon")

# 서브플롯 4: 노란 별
plt.subplot(224)
plt.scatter(x, y, s=80, c="y", marker=(5, 1))
plt.title("Yellow Star")

plt.tight_layout()
plt.show()

    subplot(221)은 subplot(2, 2, 1)과 같은 뜻이다. 2행 2열 중 첫 번째 위치에 그래프를 그린다.

    3-6. fig와 axes#

    Matplotlib을 조금 더 명확하게 다루려면 객체 지향 방식으로 fig와 axes를 사용한다.

    • fig: 전체 그림 영역
    • axes: figure 안의 개별 좌표축
    • 하나의 fig 안에 여러 개의 axes를 배치할 수 있다.
    fig, axes = plt.subplots(1, 2, figsize=(10, 4))

# 첫 번째 서브플롯: 사인 그래프
x = np.linspace(0, 10, 100)
axes[0].plot(x, np.sin(x), color="blue")
axes[0].set_title("Sine Wave")
axes[0].set_xlabel("x")
axes[0].set_ylabel("sin(x)")

# 두 번째 서브플롯: 코사인 그래프
axes[1].plot(x, np.cos(x), color="orange")
axes[1].set_title("Cosine Wave")
axes[1].set_xlabel("x")
axes[1].set_ylabel("cos(x)")

# figure 전체 제목
fig.suptitle("Trigonometric Functions", fontsize=14)
plt.tight_layout()
plt.show()

    plt.plot() 방식은 간단한 그래프를 빠르게 그릴 때 편하고, fig, axes 방식은 여러 그래프를 세밀하게 제어할 때 좋다.

    정리#

    Matplotlib의 기본 흐름은 데이터를 준비하고, 그래프 함수를 호출한 뒤, 라벨과 제목을 붙이고, 마지막에 plt.show()로 출력하는 것이다.

    • 선 그래프: plt.plot()
    • 산점도: plt.scatter()
    • 히스토그램: plt.hist()
    • 막대 그래프: plt.bar()
    • 여러 그래프 겹치기: 그래프 함수 여러 번 호출 + plt.legend()
    • 여러 그래프 나누기: plt.subplot() 또는 plt.subplots()
    • 객체 지향 방식: fig, axes 사용

    데이터 분석에서는 그래프를 예쁘게 그리는 것보다 먼저 “어떤 비교나 분포를 보여줄 것인가"를 정하는 것이 중요하다. Matplotlib은 그 기본기를 익히기에 가장 좋은 출발점이다.
