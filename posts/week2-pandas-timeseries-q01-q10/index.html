Pandas 시계열 50제: 문제 1~10#

Pandas 시계열 학습자료의 Part 1은 날짜 데이터를 만드는 방법과 변환하는 방법을 익히는 구간이다.

핵심은 다음 네 가지다.

  • pd.Timestamp : 하나의 날짜/시간 값을 표현
  • pd.to_datetime() : 문자열, 리스트, Series 등을 datetime 타입으로 변환
  • pd.date_range() : 일정한 간격의 날짜 시퀀스 생성
  • pd.period_range() : 월, 분기처럼 기간 단위의 시퀀스 생성

공통 준비 코드#

import pandas as pd
import numpy as np
import datetime

pd.set_option("display.max_columns", 15)
pd.set_option("display.width", 110)

원본 노트북에서는 Classic Models 샘플 CSV를 Google Drive에서 불러왔다. 문제 3, 4에서는 orders["orderDate"] 컬럼을 사용한다.

DATA = "/content/drive/MyDrive/Colab Notebooks/2026/이어드림스쿨6기/dataset/erd_sample"

orders = pd.read_csv(
    f"{DATA}/orders.csv",
    parse_dates=["orderDate", "requiredDate", "shippedDate"]
)

parse_dates에 날짜 컬럼을 지정하면 CSV를 읽는 시점에 문자열을 datetime 타입으로 변환할 수 있다.

Q01. 문자열을 Timestamp로 변환하기#

문자열 날짜를 Pandas의 Timestamp 객체로 만드는 방법은 여러 가지가 있다.

# 방법 1: pd.Timestamp
ts1 = pd.Timestamp("2003-01-06")

# 방법 2: pd.to_datetime
ts2 = pd.to_datetime("2003-01-06")

# 방법 3: datetime 객체를 Timestamp로 변환
ts3 = pd.Timestamp(datetime.datetime(2003, 1, 6))

print(ts1, type(ts1))
print(ts2, type(ts2))
print(ts3, type(ts3))
print("세 값이 같은가?", ts1 == ts2 == ts3)

2003-01-06 00:00:00 <class 'pandas._libs.tslibs.timestamps.Timestamp'>
2003-01-06 00:00:00 <class 'pandas._libs.tslibs.timestamps.Timestamp'>
2003-01-06 00:00:00 <class 'pandas._libs.tslibs.timestamps.Timestamp'>
세 값이 같은가? True

단일 날짜를 직접 만들 때는 pd.Timestamp(), 여러 날짜를 한 번에 변환할 때는 pd.to_datetime()을 자주 사용한다.

Q02. 다양한 형식의 날짜 문자열을 한 번에 변환하기#

날짜 문자열은 /, 영문 월 이름, - 등 여러 형식으로 들어올 수 있다. 이때 pd.to_datetime()으로 한 번에 변환할 수 있다.

raw_dates = ["2003/01/06", "Jan 9, 2003", "2003-01-10", "10-01-2003"]

parsed = pd.to_datetime(raw_dates, dayfirst=False, format="mixed")
print(parsed)
print("dtype:", parsed.dtype)

DatetimeIndex(['2003-01-06', '2003-01-09', '2003-01-10', '2003-10-01'], dtype='datetime64[ns]', freq=None)
dtype: datetime64[ns]

dayfirst=False는 10-01-2003을 2003년 10월 1일로 해석하게 한다. 만약 일-월-연도 순서라면 dayfirst=True를 고려해야 한다.

Q03. 잘못된 날짜 처리하기#

현실 데이터에는 날짜가 아닌 문자열이나 잘못된 날짜가 섞여 있을 수 있다. errors="coerce"를 사용하면 변환할 수 없는 값을 NaT로 처리한다.

messy = orders["orderDate"].astype(str).tolist() + ["NOT_A_DATE", "9999-99-99"]

parsed = pd.to_datetime(messy, errors="coerce")
print(parsed)

DatetimeIndex([...,
               'NaT', 'NaT'],
              dtype='datetime64[ns]', length=328, freq=None)

NaT는 datetime에서의 결측값이다. 숫자 데이터의 NaN과 비슷하게 생각하면 된다.

Q04. Unix epoch 초를 Timestamp로 변환하기#

Unix epoch는 1970년 1월 1일 00:00:00부터 흐른 시간을 초 단위로 표현한 값이다.

# 주문일을 epoch 초로 변환
epoch_seconds = (
    orders["orderDate"] - pd.Timestamp("1970-01-01")
) // pd.Timedelta("1s")

print(epoch_seconds)

# epoch 초를 다시 날짜로 복원
restored = pd.to_datetime(epoch_seconds, unit="s")
print(restored)

날짜끼리 빼면 Timedelta가 되고, 이를 초 단위로 나누면 epoch 초를 만들 수 있다. 반대로 pd.to_datetime(..., unit="s")를 사용하면 초 단위 숫자를 다시 날짜로 복원한다.

Q05. year, month, day 컬럼으로 날짜 조립하기#

연도, 월, 일, 시, 분이 각각 컬럼으로 나뉘어 있을 때도 pd.to_datetime()으로 날짜를 조립할 수 있다.

df_parts = pd.DataFrame({
    "year":   [2003, 2003, 2003],
    "month":  [1,    2,    3],
    "day":    [6,    14,   3],
    "hour":   [9,    13,   17],
    "minute": [0,    30,   45],
})

assembled = pd.to_datetime(df_parts)
assembled

0   2003-01-06 09:00:00
1   2003-02-14 13:30:00
2   2003-03-03 17:45:00
dtype: datetime64[ns]

컬럼명이 year, month, day, hour, minute처럼 Pandas가 인식할 수 있는 이름이면 자동으로 조립된다.

Q06. date_range로 일별 날짜 시퀀스 만들기#

pd.date_range()는 시작일과 종료일 사이의 날짜를 일정한 간격으로 생성한다.

# 일별 날짜 생성
daily = pd.date_range("2026-01-01", "2026-03-31", freq="D")
daily

DatetimeIndex(['2026-01-01', '2026-01-02', '2026-01-03', ...,
               '2026-03-29', '2026-03-30', '2026-03-31'],
              dtype='datetime64[ns]', length=90, freq='D')

주 단위 날짜도 만들 수 있다.

# freq="W"는 기본적으로 일요일 기준 주간 날짜를 반환
weekly = pd.date_range("2026-01-01", "2026-03-31", freq="W")
weekly

DatetimeIndex(['2026-01-04', '2026-01-11', '2026-01-18', ...,
               '2026-03-15', '2026-03-22', '2026-03-29'],
              dtype='datetime64[ns]', freq='W-SUN')

Q07. date_range의 다양한 freq 옵션 비교하기#

freq 옵션을 바꾸면 월말, 분기말, 시간 단위 날짜도 만들 수 있다.

# 월말
month_end = pd.date_range("2026-01-01", "2026-03-31", freq="ME")

# 분기말
quarter_end = pd.date_range("2026-01-01", "2026-03-31", freq="QE")

# 시간 단위
hourly = pd.date_range("2026-01-01", "2026-01-02", freq="h")

print(month_end)
print(quarter_end)
print(hourly)

DatetimeIndex(['2026-01-31', '2026-02-28', '2026-03-31'], dtype='datetime64[ns]', freq='ME')
DatetimeIndex(['2026-03-31'], dtype='datetime64[ns]', freq='QE-DEC')
DatetimeIndex(['2026-01-01 00:00:00', '2026-01-01 01:00:00', ...,
               '2026-01-02 00:00:00'],
              dtype='datetime64[ns]', freq='h')

자주 쓰는 freq는 D(일), W(주), ME(월말), QE(분기말), h(시간) 정도부터 익히면 좋다.

Q08. bdate_range로 영업일 기준 날짜 만들기#

pd.bdate_range()는 business day, 즉 평일 기준 날짜만 생성한다.

bdr = pd.bdate_range("2026-01-01", "2026-07-01")
bdr

DatetimeIndex(['2026-01-01', '2026-01-02', '2026-01-05', ...,
               '2026-06-29', '2026-06-30', '2026-07-01'],
              dtype='datetime64[ns]', length=130, freq='B')

기본 기준은 월요일부터 금요일까지다. 한국 공휴일까지 반영하려면 이후 문제에서 다루는 CustomBusinessDay를 사용한다.

Q09. period_range로 월별 Period 시퀀스 만들기#

period_range()는 특정 시점이 아니라 월, 분기, 연도 같은 기간을 표현한다.

pr = pd.period_range("2025-01", periods=18, freq="M")
print(pr)

# Period를 Timestamp로 변환
print(pr.to_timestamp(how="start"))
print(pr.to_timestamp(how="end"))

PeriodIndex(['2025-01', '2025-02', '2025-03', ..., '2026-06'], dtype='period[M]')
DatetimeIndex(['2025-01-01', '2025-02-01', '2025-03-01', ...,
               '2026-06-01'],
              dtype='datetime64[ns]', freq='MS')
DatetimeIndex(['2025-01-31 23:59:59.999999999',
               '2025-02-28 23:59:59.999999999',
               '2025-03-31 23:59:59.999999999', ...],
              dtype='datetime64[ns]', freq=None)

PeriodIndex는 “2025년 1월"처럼 기간 자체를 나타낸다. 필요하면 to_timestamp()로 월초나 월말 시점으로 변환할 수 있다.

Q10. Timestamp 속성 살펴보기#

Timestamp 객체에서는 연도, 월, 일, 요일, 분기, 윤년 여부 등을 바로 꺼낼 수 있다.

ts = pd.Timestamp("2026-07-01 09:30:30")

print(ts.date())
print(ts.year)
print(ts.month)
print(ts.day)
print(ts.day_name())
print(ts.quarter)
print(ts.is_leap_year)
print(ts.day_of_year)

print(pd.Timestamp.today(tz="Asia/Seoul"))

마지막 줄의 Timestamp.today()는 실행 시점의 현재 시간이 출력되므로 실행할 때마다 결과가 달라진다.

정리#

문제 1~10에서 가장 중요한 흐름은 문자열과 숫자를 datetime 타입으로 바꾸고, 필요한 날짜 시퀀스를 생성하는 것이다.

  • 단일 날짜: pd.Timestamp()
  • 여러 날짜 변환: pd.to_datetime()
  • 잘못된 날짜 결측 처리: errors="coerce"
  • epoch 초 변환: pd.to_datetime(..., unit="s")
  • 날짜 범위 생성: pd.date_range(), pd.bdate_range()
  • 기간 범위 생성: pd.period_range()
  • 날짜 속성 확인: .year, .month, .day_name(), .quarter, .is_leap_year

시계열 분석을 하려면 먼저 날짜 컬럼이 문자열이 아니라 datetime64[ns] 타입인지 확인하는 습관이 중요하다.
