강의자료/04,05 파이썬 기본 문법 이어드림스쿨 강의자료를 바탕으로, 파이썬을 처음 배울 때 꼭 알아야 할 기본 문법을 정리해 보았다.

파이썬 문법의 핵심은 값을 어떻게 표현하고, 조건에 따라 어떻게 나누고, 반복되는 일을 어떻게 줄이고, 여러 데이터를 어떻게 묶고, 기능을 어떻게 함수로 분리할 것인지 이해하는 데 있다. 문법 하나하나는 작아 보이지만, 이 조각들이 모여 프로그램의 흐름을 만든다.

1. 출력, 입력, 변수는 프로그램의 출발점이다#

print()는 원하는 값이나 문장을 화면에 출력하는 함수다. 하나의 값만 출력할 수도 있고, 콤마를 이용해 여러 값을 함께 출력할 수도 있다.

print("나의 꿈은 파이썬 정복!")
print(3, "Hello!")

input()은 사용자에게 값을 입력받는 함수다. 중요한 점은 input()으로 입력받은 값은 기본적으로 문자열이라는 것이다. 숫자처럼 계산하려면 int()나 float()을 이용해 형 변환을 해야 한다.

age = input("나이를 입력하세요: ")
print(type(age))  # str

number = int(input("숫자를 입력하세요: "))
print(number + 10)

변수는 값을 담아두는 이름이다. 같은 값을 여러 번 사용하거나, 입력받은 값을 나중에 다시 활용할 때 변수를 사용한다. 변수 이름은 알파벳, 숫자, 언더바 등을 사용할 수 있지만 숫자로 시작할 수 없고, print 같은 예약어를 변수명으로 쓰면 안 된다.

2. 자료형은 값의 성격을 정한다#

파이썬에서 값은 자료형을 가진다. 숫자, 문자열, 리스트처럼 값의 성격에 따라 사용할 수 있는 연산과 기능이 달라진다.

  • 숫자형: 정수와 실수를 다룬다.
  • 문자열: 문자들의 나열이다.
  • 리스트: 여러 값을 순서 있게 담는다.
  • 논리형: True 또는 False를 나타낸다.

숫자형은 사칙연산을 할 수 있다. +, -, *, /뿐 아니라 몫을 구하는 //, 나머지를 구하는 %, 제곱을 구하는 **도 자주 사용한다.

print(13 // 5)  # 2
print(13 % 5)   # 3
print(2 ** 4)   # 16

문자열은 +로 이어 붙이고, *로 반복할 수 있다. 문자열과 리스트처럼 순서가 있는 자료형은 인덱싱과 슬라이싱이 가능하다. 인덱스는 0부터 시작한다.

word = "Ready"
print(word[1])    # e
print(word[1:4])  # ead

논리형은 조건문에서 특히 중요하다. 비교 연산자는 결과로 True 또는 False를 돌려준다. and, or, not을 이용하면 여러 조건을 조합할 수 있다.

3. 조건문은 상황에 따라 다른 코드를 실행하게 한다#

조건문은 특정 조건이 참인지 거짓인지에 따라 실행할 코드를 나누는 문법이다. if는 조건이 참일 때 실행되고, else는 조건이 거짓일 때 실행된다. 여러 조건을 순서대로 확인하려면 elif를 사용한다.

score = 78

if score >= 90:
    print("A")
elif score >= 75:
    print("B")
else:
    print("C")

파이썬에서는 들여쓰기가 문법이다. if, elif, else 아래에 들어갈 코드는 같은 깊이로 들여써야 한다. 들여쓰기가 어긋나면 코드의 의미가 바뀌거나 오류가 발생할 수 있다.

조건문을 잘 쓰려면 먼저 문제를 조건으로 나누어 생각해야 한다. 예를 들어 로그인 정보가 맞으면 홈페이지로 이동하고, 틀리면 경고 문구를 출력하는 식이다. 프로그램은 결국 이런 작은 판단들의 모음이다.

4. 리스트와 시퀀스는 여러 값을 순서 있게 다룬다#

리스트는 여러 값을 하나의 이름으로 묶어 다루는 자료형이다. 숫자, 문자열, 다른 자료형을 함께 담을 수도 있다. 리스트는 순서가 있기 때문에 인덱싱과 슬라이싱을 사용할 수 있다.

numbers = [2, 4, 6, 8, 10]
print(numbers[2])    # 6
print(numbers[1:4])  # [4, 6, 8]

리스트에는 여러 메서드가 있다.

  • append(): 마지막에 원소를 추가한다.
  • insert(): 지정한 위치에 원소를 추가한다.
  • remove(): 처음 등장하는 특정 값을 제거한다.
  • sort(): 리스트를 정렬한다.
  • pop(): 특정 위치의 값을 꺼내고 제거한다.
  • count(): 특정 값의 개수를 센다.

문자열과 리스트는 모두 시퀀스 자료형이다. 시퀀스는 순서가 있는 자료형이므로 in으로 포함 여부를 확인하고, len()으로 길이를 구하고, +로 이어 붙이고, *로 반복할 수 있다.

letters = ["e", "l", "i", "c", "e"]
print("e" in letters)  # True
print(len(letters))    # 5

문자열에는 split()과 join()도 자주 사용된다. split()은 문자열을 기준에 따라 나누어 리스트로 만들고, join()은 리스트의 문자열들을 하나의 문자열로 합친다.

5. 반복문은 반복되는 코드를 줄인다#

반복문은 같은 일을 여러 번 수행할 때 사용한다. 파이썬에서는 for와 while을 많이 사용한다.

for문은 시퀀스의 원소를 하나씩 꺼내며 반복한다.

total = 0
for number in [1, 3, 5]:
    total = total + number
print(total)

range()는 연속된 숫자를 만들어 반복할 때 사용한다. range(5)는 0부터 4까지의 값을 만들고, range(1, 9)는 1부터 8까지의 값을 만든다.

for i in range(1, 5):
    print(i)

while문은 조건이 참인 동안 반복한다. 조건이 계속 참이면 무한 루프가 될 수 있으므로, 반복을 끝낼 조건을 반드시 신경 써야 한다. break는 반복문을 중간에 탈출할 때 사용한다.

i = 1
while i > 0:
    print(i)
    if i >= 5:
        break
    i = i + 1

6. 튜플과 딕셔너리는 데이터를 다르게 묶는다#

튜플은 여러 값을 담는 자료형이지만, 한 번 만들어지면 값을 바꿀 수 없다. 리스트는 수정이 가능하고, 튜플은 수정이 불가능하다는 점이 가장 큰 차이다. 값이 바뀌면 안 되는 데이터를 묶을 때 튜플을 사용할 수 있다.

point = (3, 5)
print(point[0])

딕셔너리는 키와 값의 쌍으로 데이터를 저장한다. 사전에서 단어를 찾으면 뜻이 나오듯, 딕셔너리에서는 키를 이용해 값을 꺼낸다.

person = {"name": "Rabbit", "age": 22}
print(person["name"])

딕셔너리에는 값을 추가하거나 삭제할 수 있고, keys(), values(), items()를 이용해 키, 값, 키-값 쌍을 꺼낼 수 있다.

person["mail"] = "rabbit@elice.com"
del person["age"]

for key, value in person.items():
    print(key, value)

딕셔너리의 키는 변할 수 없는 자료형이어야 한다. 리스트처럼 값이 바뀔 수 있는 자료형은 키로 사용할 수 없다.

7. 함수와 메서드는 코드를 재사용하게 만든다#

함수는 특정 기능을 수행하는 코드의 묶음이다. 파이썬에는 print(), input(), len(), sum(), max(), min() 같은 내장 함수가 있다. 직접 함수를 만들 때는 def를 사용한다.

def plus_double(a, b):
    c = a + b
    return 2 * c

print(plus_double(3, 4))

함수는 입력, 기능, 출력으로 생각할 수 있다. 매개변수를 통해 값을 입력받고, 함수 내부에서 작업을 수행한 뒤, return으로 결과를 돌려준다. return이 없으면 함수 안에서 계산한 값을 바깥에서 사용할 수 없다.

변수의 범위도 중요하다. 함수 밖에서 만든 변수는 전역 변수이고, 함수 안에서 만든 변수는 지역 변수다. 지역 변수는 함수 안에서만 사용할 수 있다. 이 차이를 이해해야 함수 안팎에서 값이 왜 보이거나 보이지 않는지 알 수 있다.

메서드는 특정 자료형과 연결된 함수처럼 사용할 수 있는 기능이다. 함수는 len(my_list)처럼 호출하지만, 메서드는 my_list.append(4)처럼 자료 뒤에 점을 찍고 호출한다. 리스트의 append(), count(), pop() 같은 기능이 메서드다.

마무리#

파이썬 기본 문법은 프로그램을 만드는 가장 작은 재료다. 출력과 입력으로 값을 주고받고, 변수와 자료형으로 값을 저장하고, 조건문과 반복문으로 흐름을 만들고, 리스트와 딕셔너리로 데이터를 묶고, 함수로 기능을 재사용한다.

1. 핵심 주장#

파이썬 문법을 배운다는 것은 단어를 외우는 것이 아니라, 문제를 코드의 흐름으로 바꾸는 방법을 익히는 일이다. 어떤 값을 다룰지, 어떤 조건으로 나눌지, 어떤 일을 반복할지, 어떤 기능을 함수로 묶을지를 생각하는 습관이 중요하다.

처음에는 문법 하나하나가 따로 보이지만, 실제 코드는 자료형, 조건문, 반복문, 함수가 함께 움직인다. 그래서 예제를 따라 치는 것에서 멈추지 않고, 작은 문제를 직접 코드로 바꿔보는 연습이 필요하다.

2. 중요한 개념#

  • print()는 값을 출력하고, input()은 사용자 입력을 받는다.
  • input()의 결과는 문자열이므로 계산이 필요하면 형 변환을 해야 한다.
  • 변수는 값을 저장하는 이름이고, 변수명에는 지켜야 할 규칙이 있다.
  • 숫자형, 문자열, 리스트, 튜플, 딕셔너리, 논리형은 각각 쓰임이 다르다.
  • 조건문은 if, elif, else로 상황에 따라 실행 흐름을 나눈다.
  • 리스트와 문자열은 순서가 있는 시퀀스 자료형이다.
  • 반복문은 같은 작업을 여러 번 실행할 때 사용한다.
  • 딕셔너리는 키와 값의 쌍으로 데이터를 저장한다.
  • 함수는 코드를 묶어 재사용하게 해준다.
  • 메서드는 특정 자료형에 연결된 기능이다.

3. 내가 놓치기 쉬운 부분#

가장 놓치기 쉬운 부분은 자료형이다. input()으로 받은 숫자가 실제로는 문자열이라는 점을 잊으면 100 + 300이 아니라 "100" + "300"처럼 이어 붙이기가 되어 100300이 될 수 있다.

들여쓰기도 단순한 보기 좋은 형식이 아니다. 파이썬에서 들여쓰기는 코드 블록을 구분하는 문법이다. 조건문, 반복문, 함수에서 들여쓰기가 어긋나면 의도와 다르게 실행되거나 오류가 난다.

또 하나는 함수의 return이다. 함수 안에서 print()만 하면 화면에는 보이지만, 그 결과를 다른 코드에서 사용할 수는 없다. 계산 결과를 계속 활용하려면 return으로 값을 돌려줘야 한다.

4. 현실에 적용하는 방법#

작은 프로그램을 만들 때는 먼저 입력, 처리, 출력을 나눠보면 좋다. 어떤 값을 받을지, 그 값을 어떤 자료형으로 바꿔야 하는지, 어떤 조건을 확인해야 하는지, 어떤 결과를 출력해야 하는지 정리하면 코드가 훨씬 덜 막힌다.

반복되는 코드를 발견하면 반복문이나 함수로 줄일 수 있는지 생각해볼 수 있다. 같은 print()를 여러 번 쓰고 있다면 for문을 사용할 수 있고, 같은 계산을 여러 곳에서 하고 있다면 함수로 분리할 수 있다.

데이터를 저장할 때도 자료형 선택을 고민해야 한다. 순서가 중요하면 리스트나 튜플을, 이름표를 붙여 값을 찾고 싶으면 딕셔너리를 사용한다. 값이 바뀌면 안 된다면 리스트보다 튜플이 더 적합할 수 있다.
