    Matplotlib Matplotlib은 Python에서 가장 기본적으로 많이 사용하는 데이터 시각화 라이브러리다. 데이터 시각화는 숫자나 표 형태의 데이터를 그래프, 차트 같은 시각 형태로 표현해 이해하기 쉽게 만드는 과정이다. 정보 전달 효율을 높일 수 있다. 데이터의 패턴과 상관관계를 파악하기 쉽다. 여러 값이나 그룹을 비교하기 좋다. 선 그래프, 산점도, 히스토그램, 막대 그래프 등을 세밀하게 제어할 수 있다.
