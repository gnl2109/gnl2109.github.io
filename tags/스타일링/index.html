    CSS CSS란? CSS(Cascading Style Sheet)는 HTML로 작성한 정보와 디자인을 분리하고, 문서의 레이아웃과 스타일을 정의하는 언어다. 기본 구성은 다음과 같다. 선택자 { 속성: 속성값; } 선택자: 디자인을 적용할 HTML 영역 속성: 적용할 디자인의 종류. 예: color, font-size 속성값: 속성이 수행할 구체적인 명령. 각 선언 끝에는 세미콜론(;)을 입력한다. h1 { font-size: 20px; font-family: sans-serif; color: blue; background-color: yellow; text-align: center; } CSS를 연결하는 세 가지 방법 Inline Style Sheet HTML 태그의 style 속성에 직접 작성한다. <h1 style="color: red;">coding</h1> Internal Style Sheet HTML 문서의 head 안에 style 태그로 작성한다. ...
